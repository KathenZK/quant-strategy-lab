# Tests

The root `tests/` directory covers active project code only:

- data lake layout, storage, ingestion, and quality checks,
- CLI and settings behavior,
- reusable factors/features and narrow research exporters.

Retired strategy-platform tests were removed from `archive/code/` to avoid
keeping a second platform-shaped codebase. The archive now keeps only a few
historical strategy source snapshots cited by research documents.
