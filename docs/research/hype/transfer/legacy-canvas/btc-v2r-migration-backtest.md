## 为什么迁移失败

| 原因 | 说明 |
| --- | --- |
| ADX/成交量阈值不匹配 | V2R 的 ADX28/volume_surge 是为 HYPE 强趋势波动设计的；BTC 更平滑，触发后不一定有足够延续。 |
| 仓位目标过高 | BTC ATR 更低时更容易打到 3x cap，导致每次指标退出的账户亏损被放大。 |
| 空头规则迁移失败 | BTC 空头不像 HYPE 那样短促下杀，V2R 的 15m 空头触发后经常变成反复指标退出。 |
| 指标退出过密 | BTC 1y 66 次 indicator exit，平均 -2.31%；take profit 平均 +2.14%，盈亏结构反过来了。 |
| 结论 | BTC 不应直接用 HYPE V2R；下一步应单独降低 target ATR、提高趋势质量门槛、重做多空确认。 |
