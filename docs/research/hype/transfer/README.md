# HYPE Transfer Research

This directory stores cross-asset transfer checks that start from HYPE strategy kernels but are not themselves canonical HYPE strategy-family specs.

Use explicit source and target identifiers in each report. For example, `HYPE-EMA-TB -> BTC` is a transfer check, not a new `HYPE-EMA-TB` version unless a document explicitly promotes it into that family.

Migrated legacy Canvas transfer reports live under `legacy-canvas/`.
