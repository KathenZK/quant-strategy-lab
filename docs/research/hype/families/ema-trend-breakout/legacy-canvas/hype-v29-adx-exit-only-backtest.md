## 大白话解释

| 问题 | 解释 |
| --- | --- |
| 为什么变好 | DI 反向退出会把一些还能继续走的趋势提前砍掉；只看 ADX 后，趋势还强就继续拿。 |
| 止盈增加 | 止盈次数从 V29 的 61 次变成 64 次，说明有更多单子被放到 4.30ATR 止盈。 |
| 指标退出更少也更好 | 指标退出从 17 次降到 14 次，平均亏损从 -3.44% 收窄到 -2.53%。 |
| 风险点 | 如果未来出现方向快速反转但 ADX 仍强，ADX-only 会比 DI 反向退出慢。 |
