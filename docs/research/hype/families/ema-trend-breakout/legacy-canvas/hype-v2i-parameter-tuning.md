## V2K 参数

| 项目 | 设定 |
| --- | --- |
| EMA | EMA96 / EMA384 |
| Keltner | EMA96 ± 2.5 * ATR144 |
| ADX | ADX28 >= 28；ADX exit < 18 |
| 多头确认 | 1h ADX/DI 同向确认 |
| 空头确认 | 1h bear EMA 确认 |
| 成交量 | volume surge >= 0.5；空头额外 +0.5 |
| 仓位 | 多头 min(3.0x, 0.013 / ATR672)；空头 min(1.5x, 0.0025 / ATR672) |
| 风控 | 多头 10ATR 止损 / 4ATR 止盈 / 14ATR trailing；空头 2.5ATR 止损 / 4ATR 止盈 |
| 持仓/冷却 | 多头最长 192 根 15m；空头最长 32 根 15m；冷却 16 根 15m |

V2K 的改进来自“少做、更挑剔”：Keltner 通道更宽、ADX 门槛更高、冷却更长，交易数从 145 降到 71。 它没有靠进一步加杠杆抬收益，而是减少噪音交易后提高收益回撤比。
