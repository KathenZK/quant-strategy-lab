## 执行说明

| 项目 | 说明 | 判断 |
| --- | --- | --- |
| 动态 ATR 回测逻辑 | 每根 15m 用当前 ATR 重算止盈和硬止损 | 回测更强，但实盘需要频繁改单 |
| 固定 entry ATR 逻辑 | 开仓时记录 entry_atr，止盈 = entry ± 4ATR，止损 = entry ∓ 12ATR | 更适合实盘挂交易所侧 TP/SL |
| trailing | 本次仍保留 10ATR trailing，但两版都触发 0 次 | 在 4ATR 全平结构下基本无贡献 |
| 实盘建议 | 若追求执行安全，可用固定 entry ATR，但要接受回撤更大 | 若追求历史表现，动态 ATR 更好 |
