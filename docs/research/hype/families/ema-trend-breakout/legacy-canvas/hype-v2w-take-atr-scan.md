## 大白话解释

| 问题 | 解释 |
| --- | --- |
| 为什么 5ATR 以上变差 | 止盈更远后，原本 4ATR 能落袋的交易更容易回吐，timeout 和 stop loss 开始增加 |
| 为什么 4.3 附近会更好 | 少数趋势单多拿了一段利润，但没有明显增加止损次数 |
| 为什么不直接记录新版本 | 4.30/4.55 附近有参数 cliff，说明这不是非常平滑的稳健提升 |
| 下一步 | 如果要升级版本，优先测固定 entry ATR 4.25-4.30，并做 walk-forward 或分年份/分行情验证 |
