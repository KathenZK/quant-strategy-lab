## 规则定义

| 模块 | 规则 | 说明 |
| --- | --- | --- |
| 强趋势触发 | 15m ADX28 >= 40；volume_surge_192 >= 1.0；1h ADX21 >= 30 且 DI/EMA 同向 | 只在开仓时判断 |
| 加仓方式 | 普通仓位先按 V2R target ATR 算出，再乘 1.2 / 1.3 / 1.5 | 非强信号保持原仓位 |
| cap 规则 | 主测试允许 cap 跟随乘数放大，1.5x 时最大仓位 4.5x | 另测 cap3 版本不突破 3x |
| 退出方式 | 最佳版本使用 V2R-A delayed3 指标退出 | 普通 V2R 上加仓效果不佳 |
