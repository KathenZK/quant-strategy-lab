对 V2Z 的入场过滤、方向模块、退出逻辑、风控仓位逐项消融，评估哪些参数必须保留、哪些可简化、哪些值得成为下一个候选版本。

Source: local Binance HYPE/USDT perp 15m data lake, 2025-06-16 to 2026-06-01 UTC. Includes 8.5 bps entry and exit cost plus funding.

## 总览

| 分类 | 结论 | 证据 |
| --- | --- | --- |
| 必须保留 | ADX 入场、成交量过滤、1h 确认、冷却、2ATR 后关闭指标退出 | 这些一去掉，收益或回撤明显恶化 |
| 可考虑移除 | DI 入场过滤、账户回撤 12% 降仓 | DI 入场去掉影响很小；回撤降仓只触发 1 次，去掉后收益略升且回撤不变 |
| 值得继续验证 | 指标退出只保留 ADX<22 | +2113.81% / -16.36%，收益和 Sharpe 最高，但短窗口稳定性略弱于 V2Z |
| 不建议 | 完全取消指标退出、取消冷却、取消成交量过滤 | 收益可能局部更高，但回撤和止损次数明显放大 |

## 结论清单

| 处理 | 参数 | 一句话原因 |
| --- | --- | --- |
| 保留 | ADX 入场 | 去掉后交易 80 -> 477，回撤 -49.98%，策略变成噪音交易 |
| 保留 | 成交量过滤 | 去掉后收益只剩 +256.02%，回撤扩大到 -31.37% |
| 保留 | 1h 确认 | 去掉后收益降到 +1062.08%，回撤扩大到 -20.19% |
| 保留 | 2ATR 后关闭指标退出 | 不关闭会让止盈从 60 次掉到 50 次，收益大幅下降 |
| 保留 | 16 根冷却 | 不冷却交易数增到 105，但收益降、回撤升 |
| 可删候选 | DI 入场过滤 | 去掉后收益 +1385.43%，回撤不变，只略弱于基准 |
| 可删候选 | 账户回撤 12% 降仓 | 只触发 1 次，去掉后收益 +1465.22%，回撤不变 |
| 新版本候选 | ADX exit only | 收益 +2113.81%，Sharpe 5.49，但要继续做更细验证 |
