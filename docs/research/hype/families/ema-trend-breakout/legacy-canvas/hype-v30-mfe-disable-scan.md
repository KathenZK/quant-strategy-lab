## 大白话解释

| 问题 | 解释 |
| --- | --- |
| 1ATR 的问题 | 只要小幅浮盈就关闭指标退出，后面如果行情反转，只能等硬止损或 timeout，导致止损次数变多。 |
| 2ATR 的优势 | 让已经证明方向的单子奔跑，同时还没明显证明方向的单子仍保留 ADX 认错能力。 |
| 不关闭为什么差 | 指标退出一直存在，会把很多本来能到止盈的单子提前打掉。 |
| 结论 | V30 当前 2ATR MFE 关闭指标退出仍然最合理，暂不建议改成 1ATR。 |
