测试 4ATR 先止盈一部分，剩余尾仓继续持有到指标退出、8ATR 二段止盈、移动止盈或超时。

Source: local Binance HYPE/USDT perp 15m data lake, 2025-06-16 to 2026-06-01 UTC. This canvas uses a layered-execution replay to compare variants under the same execution model.

## 结论

| 主题 | 判断 | 证据 |
| --- | --- | --- |
| 结论 | 分层止盈留尾仓没有提高收益 | 尾仓组最佳 +349.50% / -17.86%，低于 V2R-A 的 +523.08% / -15.83% |
| 主要原因 | 尾仓把已兑现的 4ATR 利润暴露回市场 | 尾仓版本指标退出次数明显增加，收益被回吐 |
| 最佳尾仓 | 70% 在 4ATR 止盈，30% 留到 8ATR 或 delayed3 指标退出 | +349.50%，回撤 -17.86%，Sharpe 3.54 |
| 建议 | 不替代 V2R / V2R-A | 如果要留尾仓，应只在更强趋势质量条件下启用，而不是每笔都留 |

## 为什么没提高收益

| 原因 | 说明 |
| --- | --- |
| 尾仓不是免费收益 | 30% 尾仓继续暴露，遇到趋势变弱时会把 4ATR 后的浮盈还回去。 |
| 无二段止盈最差 | 70/30 或 50/50 如果没有 8ATR 二段止盈，收益掉到 +221%~+259%，指标退出增加到 44 次。 |
| 8ATR 二段止盈有帮助 | 加 8ATR final take 后收益回到 +318%~+350%，但仍明显低于 V2R-A。 |
| 回撤变差 | 尾仓组最大回撤约 -17.2%~-17.9%，比 V2R-A 的 -15.8% 更高。 |
| 下一步方向 | 如果继续研究，应该只在 ADX/volume/1h 同向极强时启用尾仓，而不是所有止盈单都留尾仓。 |
