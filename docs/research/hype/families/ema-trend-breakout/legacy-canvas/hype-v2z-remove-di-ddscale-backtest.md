## 处理建议

| 参数 | 建议 | 原因 |
| --- | --- | --- |
| 账户回撤 12% 降仓 | 可以去掉 | 历史只触发很少，去掉后 1y 收益 +28.76%，回撤不变 |
| DI 入场过滤 | 可删但不优先 | 去掉后多出 2 笔交易，但收益少 +51.03%，1m/3m 回撤更差 |
| 两个一起去掉 | 不建议作为新版本 | 收益几乎等于 V2Z，但 Sharpe 更低、最大回撤略大 |
| 如果要记录新版本 | 优先只移除回撤降仓 | 比同时移除两个更干净，结果也更好 |
