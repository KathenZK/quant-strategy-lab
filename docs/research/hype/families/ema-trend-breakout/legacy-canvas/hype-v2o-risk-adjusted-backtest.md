## 结论

| 主题 | 判断 |
| --- | --- |
| 保留项 | Keltner/ADX/成交量/1h确认这套入场不动。交易数和多空结构完全相同，说明这次不是靠换信号过拟合。 |
| 有效项 | ADX exit 提到 22 明显改善收益质量；10% 回撤半仓显著压低验证段和测试段回撤。 |
| 谨慎项 | short_target 降到 0.010 进一步降回撤，但会吃掉一点收益；当前 V2O 选择的是更稳的版本。 |
| 淘汰项 | 两根确认、通道内回落立刻退出、1h确认失效立刻退出过于激进，容易减少有效趋势段，不作为本轮推荐。 |
| 定位 | V2O 更适合替代 V2M 作为高收益记录版；不是低回撤主线，但收益/回撤比明显更好。 |
