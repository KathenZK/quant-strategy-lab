## V2R 参数

| 模块 | 参数 | 原因 |
| --- | --- | --- |
| Keltner 过滤 | 关闭 | 消融显示 No Keltner 提升收益且未扩大回撤；V2R 改成强趋势延续，不再强制通道突破 |
| EMA 方向 | EMA96 > EMA384 做多；EMA96 < EMA384 做空 | 保留核心趋势方向过滤 |
| EMA 斜率 | EMA96 最近 24 根斜率同向 | 避免趋势停滞时进场 |
| ADX 强度 | ADX28 >= 28；空头额外 +8 | 保留最强有效参数；空头仍更严格 |
| DI 方向 | 多头 +DI > -DI；空头 -DI > +DI | 作为多空力量确认继续保留 |
| 成交量 | 多头 volume_surge >= 0.25；空头额外 +0.25 | 避免无量假趋势，空头继续更严格 |
| 1h 确认 | 多头用 1h ADX/DI；空头用 1h bear EMA | 保留高周期过滤 |
| 仓位目标 | 多头 target ATR 0.016；空头 0.014；cap 3x | 比 V2P 提高仓位，但用回撤降仓约束尾部 |
| 止盈/风控 | 4ATR 止盈；12ATR 止损；10ATR trailing；192 根 max hold | 止盈仍用消融里最优平衡点，尾部风控保留 |
| 指标退出 | EMA 反向 OR DI 反向 OR ADX < 22 | 不追 No indicator exit；只把 ADX exit 从 20 提到 22 |
| 冷却 | 16 根 15m bar | 保留，防止平仓后震荡重入 |
| 回撤降仓 | 当前 equity drawdown <= -12% 时，下一笔 allocation * 0.7 | 组合里新增的回撤保护 |

## 风险说明

| 问题 | 判断 |
| --- | --- |
| 为什么不是 No indicator exit | 它把很多 V2P 的指标退出拖到止盈，收益暴增，但最大回撤到 -22.92%，且出现 stop/timeout，风险结构变差。 |
| 为什么关 Keltner | 消融里 Keltner 不是强有效参数；关闭后新增 3 笔交易，主要在已有强趋势内更早参与。 |
| 为什么 ADX exit 提到 22 | ADX exit 22 单项消融比 V2P 多 +21.56% 收益且不增加回撤，说明更早识别趋势弱化有利。 |
| 最大拟合风险 | Keltner 开关和 target ATR 都是高敏感参数；V2R 必须做新增数据 walk-forward，不能直接替换实盘基准。 |
