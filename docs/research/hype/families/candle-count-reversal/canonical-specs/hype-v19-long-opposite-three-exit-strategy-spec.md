# HYPE-CC-V19 多单三阴提前平仓策略规格

本文档记录 HYPE 15m V19 策略。V19 基于 V18 ATR672 稳健版，只新增一个多单提前平仓规则。

## 1. 策略概要

- 策略名称：`HYPE V19 多单三阴提前平仓`
- 基础版本：`HYPE V18 ATR672 稳健版`
- 交易标的：`HYPE/USDT:USDT` 永续合约
- 周期：`15m`
- 交易方向：多空双向
- 入场、仓位、原 ATR 止盈、原 ATR 止损、冷却、24h 趋势禁入：全部沿用 V18
- 新增退出规则：
  - 只作用于多单
  - 多单买入后，若接下来紧接的 3 根已收盘 15m K 线全部为阴线
  - 则第 4 根 15m K 线开盘立即平仓
  - 空单不使用该规则

实盘实现时必须只使用已经收盘的 15m K 线判断是否出现连续 3 根阴线。

## 2. 与 V18 的区别

| 项目 | V18 | V19 |
|---|---:|---:|
| 信号 | 10 根里 8 根同色反转 | 同 V18 |
| 仓位 ATR | ATR672 | 同 V18 |
| 止盈 ATR | ATR672 | 同 V18 |
| 止损 ATR | ATR672 | 同 V18 |
| 24h 趋势禁入 | 5% | 同 V18 |
| 多单三阴提前平仓 | 无 | 有 |
| 空单提前平仓 | 无 | 无 |

## 3. 新增参数

| 参数 | 值 | 说明 |
|---|---:|---|
| `long_opposite_candle_exit_bars` | `3` | 多单入场后紧接 3 根反向阴线触发提前平仓 |
| `long_opposite_candle_exit_price` | `next_open` | 第 4 根 K 线开盘价平仓 |

## 4. 平仓优先级

每根 K 线处理顺序：

1. 如果已有持仓，先检查本根 `mark_high` / `mark_low` 是否触发原 V18 止损或 ATR 止盈。
2. 如果未触发原止损/止盈，且当前是多单，检查是否满足 V19 三阴提前平仓。
3. 满足则在第 4 根 K 线 `open` 平仓，并进入 V18 原冷却逻辑。

## 5. V19 新规则伪代码

```text
if position.direction == LONG:
    if bars_after_entry == 4:
        b1 = candle[entry_index + 1]
        b2 = candle[entry_index + 2]
        b3 = candle[entry_index + 3]

        if b1.close < b1.open
           and b2.close < b2.open
           and b3.close < b3.open:
            exit_at(candle[entry_index + 4].open)
```

注意：

- 只检查买入后紧接的 3 根 K 线。
- 如果第 1-3 根中任意一根不是阴线，则本次持仓不再使用该规则。
- 空单不检查 3 根阳线。

## 7. 结论

V19 在当前本地 Binance HYPE 数据上优于 V18：

- 1年收益从 `+838.25%` 提升到 `+1194.64%`
- 1年最大回撤从 `-27.96%` 降到 `-26.70%`
- 新规则触发频率较低，1年仅 `12` 次，主要用于过滤多单买入后立即连续走弱的场景
