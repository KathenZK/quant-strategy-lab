# HYPE V35 过拟合诊断

V35 = `V34` 的双向 `10/8` counter 改为双向 `12/9`。

```text
V35 = V32 + 3反提前退出 + 双向12/9退出

双向12/9：
- 反向12/9：开多后12根里9根下跌，或开空后12根里9根上涨 -> 坏单提前退出
- 顺向12/9：开多后12根里9根上涨，或开空后12根里9根下跌 -> 成熟盈利提前止盈
```

## 4. 一页结论

| 项目 | 判断 | 依据 |
|---|---|---|
| 总体判断 | 可继续观察，但不是“无过拟合风险” | `10/10` 个滚动90天窗口正收益，最差窗口 `+72.51%`；但信号 `10/8`、趋势过滤 `96/5%`、双向 `12/9` 都是高敏感参数，需要继续样本外验证。 |
| 核心信号 `10/8` | 最大依赖项，也是最大过拟合风险点 | `9/7`、`10/7`、`11/8`、`12/9` 都明显弱于 `10/8`。 |
| `target_atr_pct=0.006` | 收益放大器，不是 alpha | 交易集合不变；`0.004` Sharpe 更高、回撤更低，`0.006` 主要放大收益和回撤。 |
| 双向 `12/9` | 有效，不是孤点，但需监控 | `12/9` 最优；`10/8` 和 `15/11` 也较强，说明不是单点尖峰。 |
| 趋势过滤 `96/5%` | 关键防线，必须保留 | 无趋势过滤收益只剩 `+734.46%`，回撤扩大到 `-56.96%`。 |
| 冷却8 + 反向间隔8 | 有效过滤噪音 | 冷却 `0/4` 明显变差；反向间隔8只过滤5次，但去掉后收益降到 `+6337.18%`。 |
| 止盈止损参数 | `TP 5.5` 稳定，`SL 5.0` 不是唯一候选 | `TP 5.5` 明显优于 `5.0/6.0`；`SL 5.5/6.0` 略优，可后续单独验证。 |
| 风险倍率 | 有风控价值，但不是收益来源 | `minRisk 0.03125/0.0625/0.125` 差异很小；止损后不降仓会把回撤打到 `-58.53%`。 |
