# HYPE 1D MA7 MLT P5：机会修复与生命周期策略训练结果

## 结论

P5 学到了有用的“趋势状态分类”，也确实补入了多段 V7.1 漏掉的趋势；但它没有学会把识别结果稳定地转换成长持仓和高质量交易，最终裁决为 `V7_1_NOT_BEATEN`。

- 开发 OOF AUC `0.699`，内部确认 AUC `0.698`，后 81 日冻结验证 AUC `0.708`。这说明模型对“当前 MA7 穿越 root 是否处于稳定趋势”有真实排序信息，不再是 P2/P3 接近随机的状态。
- 全 365 日重拟合中，P5 覆盖 23 段稳定趋势中的 19 段，V7.1 覆盖 14 段；完全漏掉的趋势由 9 段降到 4 段。
- 但全训练期 P5 只有 `+303.06%`，弱于 V7.1 的 `+515.73%`；回撤 `-26.99%`，也弱于 `-18.40%`。
- 冻结后 81 日，P5 为 `-8.99% / -27.39% / 10 trades`，V7.1 为 `+28.19% / -8.52% / 3 trades`。P5 没有超过 V7.1，不能登记、不能 promotion、不能用于实盘。

## 数据隔离是否守住

守住了。

- `develop` 只加载 365 根日 K；小时线与资金费率都物理截断于 `2026-05-31 00:00 UTC`。
- 开发摘要明确记录 `holdout_read=false`。
- 模型、特征块、阈值、EMA 和状态机先写入带 SHA256 的 development manifest。
- 开发门禁通过之后，`validate` 才首次加载后 81 日。
- 验证后没有重训、重选特征或调整阈值。该窗口因 P0-P4 已经揭示，继续标记为 `reused holdout`，不是 clean OOS。

## 这一轮到底学什么

P4 的问题是候选空间被 V7.1 限死：V7.1 不入场，P4 根本没有机会补单；退出也只能固定延长三日。

P5 改成逐日二分类：一次原始 MA7 上穿或下穿之后，当前方向是否已经进入值得持有的稳定趋势状态。方向不由模型凭空猜，而由最近一次 MA7 穿越决定；模型只判断这个方向的趋势是否成熟。

监督标签来自训练期内部的 hindsight stable-trend lifecycle：

1. 7 日中心回归给出趋势方向和强度；
2. 要求 `abs(beta7/ATR7) >= 0.08` 且 `R² >= 0.35`；
3. 三状态 Viterbi 抑制频繁切换，再清理短于 3 日的非零片段；
4. 稳定趋势方向与当前 MA7 cross root 相同，`trend_active=1`，否则为 `0`。

未来信息只进入标签 `y`，从未进入特征 `X`；训练期最后 3 日标签被删除。

## 特征块选择

三个特征块都只在训练期前 285 日做固定扩展窗 OOF：

| 特征块 | 特征数 | OOF AUC | OOF balanced accuracy | 结果 |
| --- | ---: | ---: | ---: | --- |
| B1 穿越根与成熟路径 | 23 | 0.699 | 0.631 | 选择 |
| B2 + 穿越前市场结构 | 34 | 0.633 | 0.614 | 降低泛化 |
| B3 + 成交参与度与 funding | 41 | 0.628 | 0.624 | 继续降低泛化 |

最终选择最小的 B1。增加 MA30、30 日区间、压缩、成交量和资金费率并没有改善 OOF，说明在这 365 日样本里，模型最能学习的仍是“穿越之后价格怎样围绕 MA7 展开”，而不是更宽的市场背景。

B1 最重要的因子为：

| 排名 | 因子 | 重要度 | 直观含义 |
| ---: | --- | ---: | --- |
| 1 | `aligned_ma_gap_atr` | 0.297 | 价格沿穿越方向离 MA7 有多远 |
| 2 | `gap_expansion_ratio3` | 0.082 | 最近 3 日离 MA7 的距离是否持续扩张 |
| 3 | `aligned_return_3d` | 0.077 | 三日方向收益 |
| 4 | `aligned_rsi6` | 0.073 | RSI 是否支持穿越方向 |
| 5 | `gap_expansion_atr` | 0.061 | 相对穿越首日又扩张了多少 ATR |
| 6 | `cross_count14` | 0.054 | 最近 14 日是否反复假穿越 |

MA7 斜率仍在模型内，但不是最重要因子。模型认为“站上/跌破以后有没有持续离开 MA7”比单日斜率阈值更关键，这正是 P5 能补上部分 V7.1 漏单的来源。

## 三层训练表现

### 1. 开发 OOF

- 样本 165 日，正例率 `36.36%`；
- AUC `0.699`，Brier `0.207`；
- `0.5` 阈值下 accuracy `66.67%`、balanced accuracy `63.10%`、F1 `0.522`。

这是时间顺序扩展窗预测，不是把训练样本重新喂给模型后的成绩，因此比完整训练拟合更有解释价值。

### 2. 最后 80 日内部确认

模型只用前 285 日拟合，不在这 80 日重训：

| 指标 | P5 | V7.1 |
| --- | ---: | ---: |
| 净收益 | +20.48% | +21.70% |
| 1h MDD | -21.57% | -14.95% |
| 交易数 | 9 | 2 |
| 稳定趋势段任意覆盖 | 5/6 | 1/6 |
| 按天加权趋势覆盖 | 37.78% | 20.00% |

内部确认说明 P5 已经学会“补机会”，但还没有把更多机会变成更好的收益。它以更多交易、更高成本和更大回撤，换来更广的趋势覆盖。

### 3. 完整 365 日重拟合

| 指标 | P5 | V7.1 |
| --- | ---: | ---: |
| 分类 AUC | 0.931 | 不适用 |
| 净收益 | +303.06% | +515.73% |
| 1h MDD | -26.99% | -18.40% |
| 交易数 | 29 | 17 |
| 胜率 | 68.97% | 82.35% |
| Profit Factor | 4.10 | 15.03 |
| 成本/初始权益 | 18.62% | 11.53% |
| 稳定趋势段任意覆盖 | 19/23 | 14/23 |
| 按天加权趋势覆盖 | 45.86% | 41.44% |

完整训练 AUC `0.931` 是 resubstitution，只说明 ExtraTrees 能拟合这 353 个成熟样本，不能当成泛化成绩。真正值得保留的是 OOF/内部确认均约 `0.70`。

## 训练期修复了哪些 V7.1 漏单

P5 对以下典型漏单产生了同向持仓：

- `REF002`：`2025-06-16` 至 `06-19` 空头，V7.1 覆盖 `0%`，P5 覆盖 `50%`；
- `REF006`：`2025-08-04` 至 `08-13` 多头，V7.1 `0%`，P5 `50%`；
- `REF010`：`2025-10-03` 至 `10-10` 空头，V7.1 `0%`，P5 `12.5%`；
- `REF015`：`2026-01-16` 至 `01-22` 空头，V7.1 `0%`，P5 `57.1%`；
- `REF020`：`2026-04-04` 至 `04-14` 多头，V7.1 `0%`，P5 `63.6%`；
- `REF021`：`2026-04-15` 至 `04-20` 空头，V7.1 `0%`，P5 `16.7%`。

完全漏掉的训练趋势从 V7.1 的 9 段降至 P5 的 4 段；剩余四段为 `REF004/REF009/REF017/REF022`。P5 也真正执行了一次直接反手：`2026-05-15 00:00 UTC` 从空头切换为多头。

## 为什么“分类有效”却“策略失败”

### 1. 一个概率同时承担入场和退出，目标不对称

`trend_active` 适合判断“这一段像不像稳定趋势”，却不等于“今天概率稍降就应该平仓”。P5 用 `0.55` 入场、`0.45` 退出，把轻微概率波动直接变成交易动作。训练期 29 笔里有 18 笔因 `trend_probability_exit` 平仓，持仓普遍只有 1 至 10 日，长趋势仍被切碎。

### 2. 补到更多趋势，不代表每个入场点都有正期望

P5 在训练期把“任意覆盖段数”从 14 提到 19，却新增了许多边缘入场。胜率从 `82.35%` 降到 `68.97%`，PF 从 `15.03` 降到 `4.10`。模型学到的是状态相似性，不是扣除成本后的入场价值。

### 3. 交易频率吞噬了优势

P5 训练期交易数增加 `70.6%`，成本由初始权益的 `11.53%` 增至 `18.62%`。验证期也是 10 笔对 3 笔。即使方向排序有信息，频繁进出仍会把小优势耗掉。

### 4. 反手动作空间已经存在，但触发学习不足

P5 的状态机支持同一开盘直接反手，合成测试也验证了这一点；训练期真实触发 1 次，但验证期触发 0 次。问题已经从“代码不能反手”变为“模型的反向趋势概率很少同时达到冻结阈值”。

## 后 81 日冻结验证

| 指标 | P5 | V7.1 |
| --- | ---: | ---: |
| 分类 AUC | 0.708 | 不适用 |
| 净收益 | -8.99% | +28.19% |
| 1h MDD | -27.39% | -8.52% |
| 交易数 | 10 | 3 |
| 多/空 | 5/5 | 2/1 |
| 胜率 | 30.00% | 100.00% |
| Profit Factor | 0.791 | 无亏损笔 |
| 成本/初始权益 | 2.35% | 0.90% |
| 趋势段任意覆盖 | 5/7 | 3/7 |
| 按天加权趋势覆盖 | 27.12% | 45.76% |

P5 碰到了更多趋势段，却只覆盖 16 个趋势日；V7.1 虽只碰到 3 段，却覆盖 27 个趋势日。最大的差距来自：

- `REF029` 空头趋势持续 26 日，P5 覆盖 10 日，V7.1 覆盖 19 日；
- `REF030` 多头趋势持续 7 日，P5 覆盖 3 日，V7.1 覆盖 6 日；
- P5 10 笔交易中 7 笔亏损，前两笔分别约 `-11.02%`、`-7.06%`；
- 验证期没有触发直接反手。

这些验证信息只用于判分，不能反过来修改 P5。

## 这轮真正学到的教训

P5 已经证明：不断重新构造特征，确实可以让机器学习更精准地识别 MA7 穿越后的趋势成熟状态；OOF 和冻结验证 AUC 都约为 `0.70`，比 P2/P3 有明显进步。但“识别趋势状态”和“复制/超越 V7.1 的交易路径”不是同一个任务。

下一轮如果继续，不能再把一个 `trend_active` 概率同时当作入场和退出指令。仅依据训练期已经暴露的问题，应拆成三个独立学习任务：

1. `entry value`：这次补入扣除双边成本后是否值得；
2. `survival / hazard`：现有趋势在未来若干日内是否真正死亡，标签必须惩罚过早退出；
3. `reversal value`：反向 root 是否强到足以支付平仓加反手的双重成本。

同时应使用 episode/duration weighting，让长趋势日不会被大量普通空仓日和短噪声片段淹没。这些方向来自训练期的 29 笔高换手、低 PF 和长趋势切碎问题，可以在不学习后 81 日具体路径的前提下另立 P6。
