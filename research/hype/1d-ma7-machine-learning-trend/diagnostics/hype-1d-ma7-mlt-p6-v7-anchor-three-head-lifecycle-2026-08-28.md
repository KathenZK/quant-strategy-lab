# HYPE 1D MA7 MLT P6：V7.1 锚定三模型生命周期训练结果

## 结论

P6 没有通过训练期内部开发门禁，状态为 `DEVELOPMENT_FAILED_HOLDOUT_LOCKED`。后 81 日没有读取，也没有生成验证文件。

这一轮最有教学价值的现象是：完整 365 日重拟合看起来已经大幅超过 V7.1，但同样的模型一旦按时间向未来预测，三个学习任务都接近随机；最后 80 日的新增 3 笔交易全部亏损。它证明模型已经有足够容量“解释”这 365 日，却没有从这 365 日中学到稳定可迁移的入场、存活和反手规律。

| 评价层 | P6 | V7.1 | 裁决 |
| --- | ---: | ---: | --- |
| 完整 365 日重拟合净收益 | +729.80% | +515.73% | 仅样本内胜出，不代表泛化 |
| 完整 365 日 1h MDD | -17.77% | -18.40% | P6 略好 |
| 完整 365 日按天趋势覆盖 | 60.77% | 41.44% | P6 多覆盖 35 个趋势日 |
| 最后 80 日内部确认净收益 | +9.34% | +21.70% | P6 失败 |
| 最后 80 日 1h MDD | -23.59% | -14.95% | P6 恶化 8.64 个百分点 |
| 最后 80 日按天趋势覆盖 | 22.22% | 20.00% | P6 只多覆盖 1 天 |

## 数据隔离

- `develop` 只加载 365 根日 K：特征日从 `2025-05-31` 到 `2026-05-30`，训练终点开盘为 `2026-05-31 00:00 UTC`。
- 小时线和 funding 的物理读取终点都是 `2026-05-31 00:00 UTC`。
- manifest 记录 `holdout_permitted=false`，开发摘要记录 `holdout_read=false`。
- 因门禁失败，独立 `validate` 被合同和代码双重禁止；不存在 P6 的 `validation_summary.json`。
- 完整训练、OOF 和最后 80 日内部确认全部属于前 365 日，不能把完整训练拟合成绩叫作样本外。

## 这一轮与 P5 的根本区别

P5 只有一个 `trend_active` 模型，同一个概率同时控制入场和退出。P6 保留 exact V7.1 的原始交易作为 core，再把问题拆成三个彼此独立的二分类任务：

1. `ENTRY_VALUE`：V7.1 空仓区间里的 MA7 穿越候选，扣除成本后是否值得补入；
2. `SURVIVAL_3D`：当前 root 趋势是否还能存活约 3 日，用于是否延长 V7.1 的非保护性退出，以及补充仓位何时退出；
3. `REVERSAL_VALUE`：反向 raw cross 是否强到足以支付平仓、反手和最终退出成本。

P6 不允许模型改写 V7.1 的核心入场和小时级保护止损。模型只能：

- 在 V7.1 空仓区间补单；
- 对少数日线非保护性退出做动态延长；
- 补充仓位遇到强反向穿越时直接反手。

## 标签怎么构造

### ENTRY_VALUE

候选是 raw MA7 cross 后 `age=0..6` 的状态，且下一开盘不在 V7.1 core 持仓中。正例同时要求：

- 从下一开盘到 hindsight stable-trend episode 结束的净方向收益至少 `3%`；
- MFE 至少 `1.5 ATR`；
- MAE 不差于 `-1.5 ATR`。

完整训练期共有 180 个标签完整样本，正例 21 个，正例率 `11.67%`。

### SURVIVAL_3D

当前 stable direction 与 root 同向，且未来 3 日至少 2 日仍同向，标记为 1；否则为 0。它只回答“已有趋势是否继续”，不再回答“现在是否值得入场”。

完整训练期共有 350 个样本，正例 95 个，正例率 `27.14%`。

### REVERSAL_VALUE

只在 raw cross 日产生候选。用新方向的下一开盘观察未来最多 14 日，正例同时要求：

- 扣除 `0.42%` 三段成本后的最佳方向收益至少 `4%`；
- MAE 不差于 `-1.5 ATR`；
- stable direction 在未来 2 日内确认新方向。

完整训练期共有 81 个样本，正例 22 个，正例率 `27.16%`。

所有未来路径只进入标签 `y`，不进入实时特征 `X`；边界处的未来不完整样本被 censor。

## 使用了哪些特征

ENTRY 和 REVERSAL 各使用 29 个因果特征：P5 的 23 个 root/path 特征，加上穿越前位置与当前 root 生命周期的 6 个补充描述：

- `pre_cross_gap_atr`：穿越前一日距离 MA7 的方向化位置；
- `cross_jump_atr`：本次穿越跳过 MA7 的幅度；
- `aligned_pre_cross_return_3d`：穿越前三日是否已经向新方向蓄力；
- `prior_opposite_run`：穿越前在 MA7 反侧连续停留多久；
- `root_peak_gap_atr`：本 root 曾经离 MA7 最远多少 ATR；
- `root_gap_giveback_atr`：相对 peak gap 已经回吐多少。

SURVIVAL 在这 29 个特征之上再增加 7 个持仓生命周期特征，共 36 个：

- 从 root 起点计算的浮盈、MFE、MAE 和价格回吐；
- 距最近有利收盘极值的天数；
- 连续处于 root 同侧的天数；
- MA7 一日斜率相对三日前的衰减。

P5 已证明会降低 OOF 的 MA30、30 日压缩、成交量和 funding 扩展块没有重新加入。

## 模型与交易阈值

三个头都使用冻结的低深度 ExtraTrees：600 棵树，`max_depth=5`、`min_samples_leaf=6`、`max_features=0.75`、类别平衡、固定随机种子 `20260828`。本轮没有搜索模型、特征块、阈值或持有天数。

冻结阈值为：

- 补入：`P(entry)>=0.65`；
- V7.1 退出可开始延长：`P(survival)>=0.60`；
- 连续两日 `P(survival)<0.35` 才结束动态持仓；
- 直接反手：`P(reversal)>=0.70`。

## 三层训练表现

### 1. 完整 365 日重拟合：表面上非常成功

| 学习头 | 样本内 AUC | F1 |
| --- | ---: | ---: |
| ENTRY_VALUE | 0.9997 | 0.824 |
| SURVIVAL_3D | 0.9467 | 0.755 |
| REVERSAL_VALUE | 0.9753 | 0.846 |

| 策略指标 | P6 | V7.1 |
| --- | ---: | ---: |
| 净收益 | +729.80% | +515.73% |
| 1h MDD | -17.77% | -18.40% |
| 交易数 | 25 | 17 |
| 胜率 | 76.00% | 82.35% |
| Profit Factor | 9.90 | 15.03 |
| 成本/初始权益 | 20.29% | 11.53% |
| 趋势段任意覆盖 | 19/23 | 14/23 |
| 按天趋势覆盖 | 110/181，60.77% | 75/181，41.44% |

样本内 P6 新增 8 笔 supplemental entry，并动态延长 3 笔 V7.1 core trade；没有一次满足条件的直接反手。它把完全漏掉的趋势段从 9 段降到 4 段，样本内收益也比 V7.1 高 214.07 个百分点。

但三个 AUC 接近 1 正是警报：标签直接描述这 365 日后续路径，树模型可以利用大量路径组合把已发生结果分开。该成绩只说明拟合能力足够，不能证明下一段行情还能分开。

### 2. 扩展窗 OOF：三个头都未达到门禁

固定 OOF 测试区间为 `[120,160)`、`[160,200)`、`[200,240)`、`[240,285)`，每折只能用它之前的数据，并额外 purge 3 日。

| 学习头 | OOF 样本 | 正例率 | AUC | Balanced accuracy | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| ENTRY_VALUE | 104 | 7.69% | 0.581 | 0.490 | 0.087 |
| SURVIVAL_3D | 165 | 26.67% | 0.530 | 0.507 | 0.286 |
| REVERSAL_VALUE | 42 | 28.57% | 0.514 | 0.467 | 0.286 |

三个 AUC 都接近 `0.5`，ENTRY 和 SURVIVAL 还低于冻结的 `0.60` 门槛。高 accuracy 没有意义：ENTRY 的正例只有 8 个，几乎总猜负例也会有很高 accuracy，所以必须看 AUC、balanced accuracy、precision 和 recall。

### 3. 最后 80 日内部确认：多识别一丁点，新增交易全部亏损

该模型只用前 285 日拟合，最后 80 日不重训、不调阈值。

| 学习头 | 样本 | 正例率 | AUC | F1 |
| --- | ---: | ---: | ---: | ---: |
| ENTRY_VALUE | 43 | 30.23% | 0.382 | 0.182 |
| SURVIVAL_3D | 74 | 36.49% | 0.725 | 0.577 |
| REVERSAL_VALUE | 12 | 25.00% | 0.222 | 0.000 |

SURVIVAL 在这一个 80 日区间表现出局部信息，但 ENTRY 和 REVERSAL 明显失效。ENTRY 的正例率从 OOF 的 `7.69%` 跳到内部确认的 `30.23%`，说明“值得补入”的基准概率发生了很强的时期漂移。

内部确认的 P6 比 V7.1 多做 3 笔补充交易：

| 入场 | 方向 | 持有 | 净收益 | 退出 |
| --- | --- | ---: | ---: | --- |
| 2026-04-20 | 空 | 4 日 | -1.66% | 连续两日 survival 低 |
| 2026-04-26 | 多 | 3 日 | -3.48% | 反向 root，只平仓未反手 |
| 2026-05-12 | 空 | 3 日 | -5.35% | 下一笔 V7.1 core 入场 |

同期最后一笔 V7.1 多单仍赚 `+30.69%`。所以 P6 的趋势覆盖只从 `20.00%` 增加到 `22.22%`，却用三笔全亏的交易把净收益从 `+21.70%` 降到 `+9.34%`，并把 MDD 从 `-14.95%` 扩大到 `-23.59%`。

## 开发门禁逐项裁决

| 门禁 | 要求 | 结果 | 通过 |
| --- | --- | ---: | --- |
| ENTRY OOF AUC | >= 0.60 | 0.581 | 否 |
| SURVIVAL OOF AUC | >= 0.60 | 0.530 | 否 |
| 内部确认净收益 | P6 > V7.1 | 9.34% < 21.70% | 否 |
| 内部确认趋势覆盖 | P6 >= V7.1 | 22.22% > 20.00% | 是 |
| 内部确认 MDD | 不恶化超过 2pp | 恶化 8.64pp | 否 |
| 内部确认交易数 | <= V7.1 + 4 | 5 <= 6 | 是 |

六项只通过两项，故后 81 日保持锁定。

## 为什么特征更多仍没学会“值得在哪入场、应该持有多久”

### 1. 主要瓶颈不是再加几个因子，而是每个任务的有效样本太少

完整训练只有 21 个 ENTRY 正例、22 个 REVERSAL 正例；OOF 的 ENTRY 正例更只有 8 个，REVERSAL 样本总共 42 个。29 个特征面对如此少的正例，很容易形成只适用于某几段历史的组合规则。

### 2. hindsight 标签比真实决策边界干净得多

`ENTRY_VALUE` 用事后稳定趋势 episode 的结束点计算收益；现实中模型不知道 episode 何时结束。它虽然没有把未来信息放进 `X`，但 `y` 本身非常依赖少数完整趋势路径，导致样本内极易分开、时间外推却不稳定。

### 3. “趋势还活着”不等于“延长一定比 V7.1 平仓更好”

SURVIVAL 的内部确认 AUC 达到 `0.725`，但两笔 V7.1 core exit 都没有达到 `0.60` 的启动阈值，所以没有产生一次 core 延长。分类头局部有效，不代表能在冻结动作阈值下改善交易。

### 4. 反手学习几乎没有统计功效

只有 raw cross 日才有 REVERSAL 候选，OOF 只有 42 个样本。P6 完整训练和内部确认都没有触发直接反手，因此这轮并没有证明模型学会了反手。

### 5. 样本内超额来自“知道哪些例外值得做”

完整重拟合准确挑中了多笔 V7.1 漏单，所以收益和覆盖显著上升；到了内部确认，它又挑了 3 笔看起来相似、实际全亏的补单。这就是过拟合在交易路径上的具体表现，不是回测引擎或成本口径差异。

## 这轮留下什么，下一步不该做什么

P6 的三头拆分在问题定义上比 P5 合理，特别是独立的 survival 生命周期特征值得保留为研究思路；但当前 HYPE 单资产 365 日样本不足以可靠训练 29/36 维、三个树模型。继续在同一 365 日反复增加特征、调阈值，只会进一步拟合这 21 个入场正例和 22 个反手正例。

下一轮若继续，不能依据后 81 日，也不应继续扩大特征数。更合理的教学实验是先降低问题自由度：

1. 固定 V7.1 core，仅训练一个 survival/hazard 头，暂时取消补入和反手；
2. 把 daily row 改成 episode 级或 pairwise 排序，减少同一趋势多日样本造成的伪样本量；
3. 使用跨资产但同定义的 MA7 episode 扩大训练样本，再把 HYPE 365 日仅作为目标资产校准；
4. 或直接用可解释的少量特征和正则化模型，检查究竟有没有稳定信号，再决定是否回到树模型。

这些都应另立 P7 合同。P6 不验证、不登记、不 promotion、不用于实盘。
