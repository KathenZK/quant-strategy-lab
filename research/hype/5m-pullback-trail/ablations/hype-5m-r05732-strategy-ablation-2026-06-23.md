因此，本报告里的回撤更接近实盘路径；此前生存前沿报告里的回撤可视为偏保守压力口径。

## 指标定义

基础指标来自 `5m` K 线：

- `EMA21/EMA96`：定义局部多空方向。
- `EMA96/EMA384`：定义更高周期方向强度。
- `ATR14`：止损、止盈、移动止损距离。
- `ROC48`：方向动量。
- `RSI14`：方向 RSI。
- `CHOP14`：震荡程度。
- `CMF20`：方向资金流。
- `eff96`：96 根价格效率。

方向化指标：

```text
side = +1 when EMA21 > EMA96
side = -1 when EMA21 < EMA96
dir_roc = side * ROC48
dir_htf = side * (EMA96 - EMA384)
dir_cmf = side * CMF20
dir_rsi = RSI14 for long, 100 - RSI14 for short
```

## 开仓信号

### 多头开仓

当前 bar 收盘时同时满足：

1. `EMA21 > EMA96`。
2. 趋势年龄 `regime_age >= 3` 且 `regime_age <= 2000`。
3. `abs(close / EMA21 - 1) <= 0.06`。
4. `dir_roc >= -0.01`。
5. `55 <= RSI14 <= 72`。
6. `CHOP14 <= 62`。
7. `CMF20 >= -0.30`。
8. `eff96 >= 0.025`。
9. `low <= EMA21 * (1 + 0.0025)`，价格曾回踩到 EMA21 附近。
10. `close > EMA21`，收盘重新站回 EMA21。
11. `close > open`，当前 K 是阳线。
12. `EMA96 - EMA384 >= 0.688442`。

满足后，在下一根 5m K 的开盘价开多，并按 `+0.01%` 滑点处理。

### 空头开仓

当前 bar 收盘时同时满足：

1. `EMA21 < EMA96`。
2. 趋势年龄 `regime_age >= 3` 且 `regime_age <= 2000`。
3. `abs(close / EMA21 - 1) <= 0.06`。
4. `dir_roc >= -0.01`，这里 `dir_roc = -1 * ROC48`。
5. `55 <= 100 - RSI14 <= 72`。
6. `CHOP14 <= 62`。
7. `-1 * CMF20 >= -0.30`。
8. `eff96 >= 0.025`。
9. `high >= EMA21 * (1 - 0.0025)`，价格曾反抽到 EMA21 附近。
10. `close < EMA21`，收盘重新跌回 EMA21 下方。
11. `close < open`，当前 K 是阴线。
12. `-(EMA96 - EMA384) >= 0.688442`。

满足后，在下一根 5m K 的开盘价开空，并按 `0.01%` 滑点处理。

## 持仓规则

- 信号确认 bar 不成交，只在下一根 bar 开盘成交。
- 开仓后前 `6` 根 K 不触发止损、止盈、EMA 退出。
- 由于 `min_hold_bars=6`，最早实际持仓 `7` 根 K，约 `35` 分钟。
- 同一时间只保留一笔仓位。已有仓位未退出时，后续信号跳过。
- `cooldown_bars=0`，平仓后下一根符合条件的信号可以继续开仓。

## 平仓规则

### 多头

- 初始止损：`entry_price - 0.75 * ATR14(signal_bar)`。
- 初始止盈：`entry_price + 1.875 * ATR14(signal_bar)`。
- 移动止损：`max(initial_stop, previous_peak - 0.75 * ATR14(current_bar))`。
- `previous_peak` 只使用当前 bar 之前的最高价，避免同 bar 未来函数。
- 若当前 bar 同时触发 stop 和 target，代码优先按 stop 处理，口径偏保守。
- 若到 `max_hold_bars` 仍未触发任何事件，按当前 bar 收盘价平仓。

### 空头

- 初始止损：`entry_price + 0.75 * ATR14(signal_bar)`。
- 初始止盈：`entry_price - 1.875 * ATR14(signal_bar)`。
- 移动止损：`min(initial_stop, previous_trough + 0.75 * ATR14(current_bar))`。
- `previous_trough` 只使用当前 bar 之前的最低价。
- 同 bar stop 和 target 同时触发时，优先按 stop 处理。
- 若到 `max_hold_bars` 仍未触发任何事件，按当前 bar 收盘价平仓。

平仓价格按 `0.01%` 滑点处理，并扣除双边手续费 `0.08%`。

## 消融结论

第一，策略真正的核心不是 `EMA21/96` 单独本身，而是“趋势方向 + 延迟退出”的组合。单独只做多或只做空，年化都从 `29.07x` 降到 `5x` 左右，说明多空互补很重要。

第二，`trail_atr=0.75` 和 `min_hold_bars=6` 是最核心的两个持仓参数。删除移动止损后，胜率从 `59.18%` 降到 `36.02%`；删除最小持仓后，胜率降到 `32.26%`，回撤放大到 `-79.35%`。这说明策略不是靠入场即刻判断对错，而是需要至少约 35 分钟让趋势恢复，然后用紧移动止损收割路径。

第三，`dir_htf >= 0.688442` 不是收益核心，而是体验和胜率约束。删除后交易数从 `1340` 增至 `5380`，年化暴涨，但最差切片胜率降到 `54.66%`。如果追求快速验证，可以单独研究“无 final filter 的高频版”；如果追求胜率 `58%+` 的持有体验，保留 final filter 更合适。

第四，`pullback_buffer=0.0025` 偏保守。放宽到 `0.01` 后，全样本年化升到 `69.37x`，最差切片胜率 `56.85%`。这说明当前基线可能为了胜率和形态纯度牺牲了大量收益，后续最值得研究的改良方向是 `pullback_buffer=0.01` 或删除严格回踩要求。

第五，`tp_atr=1.875` 不是必需项。提高止盈到 `3.0` 或删除固定止盈都提升收益，且不改变胜率。这说明退出主要依赖移动止损，固定止盈可能截断了部分趋势收益。

第六，`max_hold_bars=576`、`donchian=96`、`breakout_buffer=0.002`、`max_dist_ema=0.06`、`max_regime_age=2000`、`exit_ema=0` 在当前基线下几乎不产生效果。它们可以在实盘代码中保留为配置项，但不是当前策略的有效边际来源。

## 实盘建议

当前主推版本仍然是：

```text
HYPE_PP_R05732__dir_htf_ge_0.688442
```

理由：

- 每月约 `105` 笔，全样本频率足够，最近 forward 月化约 `191` 笔。
- 多空都有效，不是纯单边顺风策略。
- 最差切片胜率 `58.29%`，payoff `2.19`。
- 平均持仓约 `35.6` 分钟，适合快速积累实盘样本。

但后续不应只上线一个版本。建议并行 dry-run 三条路径：

1. 基线版：`EMA21/96 + pullback_buffer=0.0025 + dir_htf >= 0.688442`。
2. 高频版：删除 final filter，观察胜率是否能稳定高于 `55%`。
3. 放宽回踩版：`pullback_buffer=0.01`，观察收益提升是否来自真实边际，而不是过拟合。

实盘验收建议先看 `150-300` 笔交易：

- 净胜率不低于 `56%`。
- payoff 不低于 `1.8`。
- profit factor 不低于 `1.3`。
- 多头和空头都不能单边失效。
- 平均滑点不能显著高于回测假设。
- 若连续 `100` 笔后胜率低于 `52%` 且 payoff 低于 `1.5`，应暂停。
