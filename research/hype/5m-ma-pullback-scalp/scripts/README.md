# Scripts

One-off reproducible scripts for `HYPE-5M-MA-Pullback-Scalp`.

- `research_hype_5m_ma_pullback_scalp.py`: executable search for the two-moving-average pullback scalp pattern on Binance HYPEUSDT `5m`.
- `research_hype_5m_ma_pullback_scalp_robustness.py`: local neighborhood robustness check around paper candidate rows from the first search.
