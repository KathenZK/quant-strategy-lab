# HYPE-CC-V35 参数过拟合再诊断 2026-06-29

## 结论

`HYPE-Candle-Count-Reversal-V35` 的实盘失败不能只解释为“短期市场风格不适配”。更准确的诊断是：

```text
当前市场风格不适配暴露了 V35 的样本内特化 / 过拟合风险。
```

V35 不是单个参数孤点造出来的策略，它继承了 HYPE-CC 从 V13/V18/V21 以来的多个有效结构：`10/8` candle-count reversal、ATR672、24h 趋势禁入、冷却、反向间隔和止损后降仓。但 V35 在后期继续叠加 `target_atr_pct=0.006`、`min_take_profit_pct=0.020`、双向 `12/9` counter，并把收益排序推到最高。6 月 OOS proxy 和 Binance live 说明，这组样本内最优组合对新行情的承受力不足。

## 过拟合风险分层

| 参数 / 规则 | V35 值 | 风险等级 | 重新诊断 |
| --- | ---: | --- | --- |
| 核心信号 `lookback/min_count` | `10/8` | 高 | 最大 alpha 来源，也是最大样本内依赖点。邻域 `9/7`、`10/7`、`11/8`、`12/9` 都明显弱于 `10/8`。这说明 V35 很依赖一个特定节奏：15m 上约 2.5 小时内 8 根同色 K 后反转。6 月实盘段正是这个节奏失效。 |
| `trend_window_bars` | `96` | 高 | 24h 窗口是强防线，但 `96` 相比 `72/120/144/192/288` 优势过大。去掉趋势过滤会显著恶化，说明机制必要；但 `96` 本身很像被历史行情校准到的最佳相位。 |
| 双向 counter | `12/9` | 中高 | `12/9` 不是完全孤点，`15/11` 也强；但它是 V34 后期从 `10/8` 改出来的收益增强层，触发次数不多，却显著影响收益排序。OOS/live 里没有证明这层仍有效。 |
| `target_atr_pct` | `0.006` | 中高 | 不是 alpha，只是仓位放大器。`0.004` Sharpe 更高、回撤更低；`0.006` 放大收益，也同步放大 6 月亏损和实盘心理/保证金压力。 |
| `take_profit_atr_multiplier` | `5.5` | 中 | 5.5ATR 比 5.0/6.0 好，且从 V18.1/V25/V29 延续下来，不是 V35 新孤点。但 TP 与行情波动节奏绑定，样本外仍要重测。 |
| ATR 窗口 | `672` | 中 | ATR672 是 V18 以来的主中枢，allocation 端对 384/512/768 不太敏感；但 SL/TP 窗口更依赖 672 附近。属于有结构依据但仍有样本内选择痕迹。 |
| `cooldown_bars` | `8` | 中 | 冷却 0 明显变差，12 也弱于 8。它是有效噪声过滤，但 `8` 根 15m 约 2 小时，和 `10/8` 信号节奏共同构成相位匹配，需样本外验证。 |
| `opposite_signal_gap_bars` | `8` | 中低 | 去掉后收益下降但不崩，只过滤少量交易。更像有用的反复横跳过滤，不是主要过拟合点。 |
| `min_take_profit_pct` | `0.020` | 中低 | `0.015/0.020` 结果相同，`0.025` 收益下降。它不是尖峰，但属于后期微调层。 |
| `stop_loss_atr_multiplier` | `5.0` | 中低 | `5.5/6.0` 略优或接近，说明 `5.0` 不是唯一最佳。当前实盘止损多，不代表这个参数单独过拟合，而是信号进入了不适配 regime。 |
| `min_risk_multiplier` | `0.0625` | 低 | `0.03125/0.0625/0.125` 差异很小。它主要限制连续止损后的最低仓位，不是收益来源。 |
| `stop_loss_risk_multiplier` | `0.5` | 中低 | 止损后不降仓会把回撤打到不可接受，说明降仓机制必要。`0.25` Sharpe 更高但收益低；`0.5` 是收益/风险折中，不是核心 alpha。 |
| `max_allocation` | `3.0` | 中高 | 与 `target_atr_pct` 一样主要放大风险收益，不提供方向 alpha。实盘小账户下尤其会放大路径风险和执行摩擦占比。 |

## 关键证据

### 1. 核心信号是最大的尖点

`10/8` 的全样本收益 `+8357.56%`、Sharpe `4.63`，但邻域明显塌陷：

```text
9/7   -> +221.84%,  Sharpe 1.57, DD -67.39%
10/7  -> +109.81%,  Sharpe 1.21, DD -60.97%
10/8  -> +8357.56%, Sharpe 4.63, DD -33.26%
11/8  -> +343.81%,  Sharpe 1.84, DD -61.93%
12/9  -> +387.90%,  Sharpe 2.00, DD -45.15%
```

这是最强过拟合信号：策略核心不是“同色 K 越极端越好”的平滑关系，而是集中在 `10/8` 这个节奏点。

### 2. 趋势过滤必要，但 `96` 很敏感

趋势过滤不能去掉：去掉后收益只剩 `+734.46%`，回撤扩大到 `-56.96%`。但窗口扫描显示 `96` 明显优于两侧：

```text
72  -> +3278.83%, Sharpe 3.74
96  -> +8357.56%, Sharpe 4.63
120 -> +967.92%,  Sharpe 2.76
144 -> +1661.22%, Sharpe 3.22
288 -> +2113.32%, Sharpe 3.53
```

因此趋势过滤这个机制可信度高，`96` 这个精确窗口可信度低于机制本身。

### 3. V35 后期收益主要来自叠加优化，不是新 alpha

从里程碑看，后期版本的收益阶梯大致是：

```text
V29: target 0.005 + TP 5.5              -> +3025.25%
V30: minTP 2.0% + counter 14/10          -> +3719.40%
V32: target 0.006                        -> +6265.50%
V34: 双向 10/8 counter                   -> +7169.51%
V35: 双向 12/9 counter                   -> +8357.56%
```

这里 `V32` 的大幅提升主要是加仓，`V34/V35` 是 exit/counter 微调。也就是说，V35 的最高收益来自“稳定结构 + 后期收益增强层 + 更高仓位”的组合；后两者过拟合风险明显高于早期结构。

### 4. OOS 和实盘已经否定“稳健到可 live”

6 月 OHLCV proxy replay：

```text
2026-06-01 03:00 -> 2026-06-26 04:00: -18.98%, 24 trades, take 11 / stop 11 / early 2
2026-06-05 00:00 -> 2026-06-26 04:00: -18.12%, 19 trades, take 9 / stop 10
2026-06-10 00:00 -> 2026-06-26 04:00: -27.37%, 15 trades, take 6 / stop 9
```

Binance live 剔除测试单后：

```text
18 closed official strategy trades
take 5 / stop 12 / early_main 1
net -30.9941 USDT
fees + stop/take adverse slippage about 1.05 USDT
```

实盘亏损主体不是滑点或手续费，而是信号/退出组合在新行情中转成了止损密集段。

## 哪些参数最应该判为过拟合

### 第一优先级：暂停信任

这些参数必须视为过拟合高风险，不能继续按回测最优值信任：

```text
lookback=10 / min_count=8
trend_window_bars=96
target_atr_pct=0.006
双向 counter 12/9
```

其中 `10/8` 和 `96` 是结构级风险；`0.006` 和 `12/9` 是后期收益增强风险。

### 第二优先级：保留机制，但重估数值

这些机制可能仍有价值，但具体数值要重新做 live-realistic search：

```text
ATR672 for allocation / SL / TP
take_profit_atr_multiplier=5.5
cooldown_bars=8
opposite_signal_gap_bars=8
stop_loss_risk_multiplier=0.5
```

### 第三优先级：不是主要过拟合点

这些不是当前失败主因：

```text
min_risk_multiplier=0.0625
min_take_profit_pct=0.020
stop_loss_atr_multiplier=5.0
```

它们有调参痕迹，但证据不支持把它们列为 V35 崩坏的核心原因。

## 重新评估建议

如果要继续研究 HYPE-CC，不应从 V35 继续微调，而应回退到更少后期增强层的基线：

1. 以 `V18.1` / `V21` / `V25` / `V31` 作为候选基线，优先使用较低 `target_atr_pct=0.004~0.005`。
2. 对 `10/8` 做 regime split：强单边、高波动、震荡、低波动分别统计；如果 `10/8` 只在历史某类 regime 有效，就不能做通用 live 策略。
3. 对 `trend_window_bars` 不再只测 `72/96/120`，而要按 1h/4h/1d 多层趋势条件重构，避免精确 96 根相位依赖。
4. `12/9 counter` 需要单独 OOS：先关闭它跑 live-realistic，再比较 `10/8`、`12/9`、`15/11`，不能因为全样本最高就保留。
5. 所有回测必须改成 live-realistic：next-open/next-tick 入场、early exit 不按已知 close 成交、stop/take 使用 market slippage stress。

当前决策：`HYPE-CC-V35` 维持 `live-underperformance / execution-risk diagnostic`，不再作为 live candidate 或收益型 paper-live candidate。
