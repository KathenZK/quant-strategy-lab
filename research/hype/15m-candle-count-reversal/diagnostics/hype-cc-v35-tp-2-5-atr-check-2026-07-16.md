# HYPE-CC-V35 TP 2.5 ATR 单参数诊断（2026-07-16）

## 结论

同事提出“将 V35 的 TP 从 `5.5 ATR` 改为 `2.5 ATR` 后，最近 30 天可能转正”。按单参数消融复现后，该说法不成立：

| 最近 30 天 | V35 TP5.5 | TP2.5 诊断 |
| --- | ---: | ---: |
| 收益 | -19.38% | **-46.70%** |
| 最大回撤 | -30.30% | **-49.40%** |
| Sharpe | -2.73 | **-8.21** |
| 胜率 | 34.62% | 41.38% |
| 开仓 / 已平仓 | 27 / 26 | 30 / 29 |
| 平均实际 TP | 3.44% | 2.09% |

TP2.5 确实把胜率提高 `6.76` 个百分点，但收益和回撤显著恶化，不能作为 V35 修复方案，不登记新版本，也不修改 runner / dry-run 配置。

## 变更边界

本轮只修改：

```text
take_profit_atr_multiplier: 5.5 -> 2.5
```

其余 V35 参数不变：

```text
take_profit_atr_window = 672
min_take_profit_pct = 0.020
max_take_profit_pct = 0.035
stop_loss_atr_multiplier = 5.0
min_stop_loss_pct = 0.025
max_stop_loss_pct = 0.035
```

因此 TP2.5 的实际公式是：

```text
take_profit_pct = clamp(atr_pct_672 * 2.5, 0.020, 0.035)
```

不是固定 `2.5%`，也没有取消原 `2%–3.5%` 上下限。

- 缺失、重复、关键空值、raw / normalized 不一致：均为 0。

TP2.5 在所有有足够已平仓交易的近期切片中都弱于原 V35；并非只在最近 30 天偶然失效。

## 为什么胜率提高但收益更差

最近 30 天：

- V35：9 胜、17 负；
- TP2.5：12 胜、17 负。

TP2.5 没有减少亏损交易数量，只多实现了 3 次更小的盈利。与此同时，平均 TP 从 `3.44%` 降到 `2.09%`，而止损仍为 `2.5%–3.5%`，单笔盈亏比明显恶化；更早离场还改变后续开仓与风险倍率路径，使开仓从 27 增至 30，并增加成交成本。

因此，“胜率更高”不能推出“收益转正”。本轮恰好是高胜率、低盈亏比导致总结果更差的反例。

## 决策

1. 拒绝 `TP=2.5 ATR` 单参数修改。
2. 不登记 `HYPE-CC-V36`。
3. 不修改 V35 规格、runner 或 dry-run 配置。
4. 不以胜率单独评估 TP；后续 TP 研究必须同时检查收益、回撤、Sharpe、盈亏比、交易路径和 OOS 稳健性。
