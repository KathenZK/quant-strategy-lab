## 3. 为什么"反复开平"反而是对的

| 机制 | 解释 |
| --- | --- |
| 止盈落袋 + 立即重入 = 动态金字塔 | 每次 5ATR 止盈后用最新 ATR 重新计算杠杆再上车，新仓止损锚定在新入场价。趋势延续时这等价于不断锁定利润并金字塔式复利，趋势反转时只回吐最后一笔小仓位。 |
| 持仓不动 = 全程暴露 mark-to-market 回撤 | trailing/EMA 退出版本必须把浮盈回吐 4~6 个 ATR 才出场，权益曲线回撤直接恶化到 -28% ~ -56%，Sharpe 从 4.8 掉到 2~3。 |
| 重入成本远小于金字塔收益 | 52 次重入多付约 52 x 17bps x 2.7 杠杆 = 累计约 24% 成本，但 baseline 比最好的让利润奔跑变体多赚 5000+ 个百分点。 |
| 胜率结构被破坏 | 5ATR 止盈是 80% 胜率的来源 (75/100 笔止盈出场)。改 trailing 后胜率掉到 44~58%，策略从高胜率结构变成低胜率长持有结构，与入场信号(短窗口动量确认)不再匹配。 |

## 4. 结论

> **提示**
> 假设被数据否定：止盈-重入循环不是平错了仓，而是 V34 的核心盈利机制。唯一值得采纳的改动是把 timeout 从 192 根放宽到 384 根。

| 问题 | 判断 | 依据 |
| --- | --- | --- |
| 反复平仓再开仓是缺陷吗 | 不是，是核心盈利机制 | 90% 重入发生在止盈后；去掉这个循环收益从 +5840% 掉到 +127% ~ +797% |
| 让利润奔跑(trailing)可行吗 | 不可行 | 全部 11 个变体收益、回撤、Sharpe、胜率四项全面变差，且 HL/OKX 同样变差 |
| 放宽止盈可行吗 | 不可行 | TP 8/10ATR 收益减半、回撤扩大 10~14pp、交易数减少 |
| 用户思路中正确的部分 | timeout 退出确实错平了趋势单 | 2 笔 timeout 平仓是趋势中错平；timeout 192 -> 384 后三家交易所同向改善 |
| 唯一推荐的改动 | timeout 384 (或等价地去掉) | Binance +6474% / -23.49% / Sharpe 4.94，HL +543%、OKX +946%，3m/6m 窗口同步改善 |
