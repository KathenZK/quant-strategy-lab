## 参数判断

| 问题 | 结论 | 说明 |
| --- | --- | --- |
| delayed3 是否有效 | 有效，但不是唯一来源 | V2S 比 V2R 多 +35pct，主要来自少被提前洗出；但 delay4/ADX22 也能更高，说明退出参数仍敏感。 |
| ADX exit 20 是否最好 | 不是 | 本轮 delayed3 + ADX22 达 +605.28% / -15.23%，优于 V2S；但这是在 V2S 之后继续调参，拟合风险更高。 |
| 指标退出能否删除 | 不建议 | No indicator exit 收益最高，但 Train 回撤 -25.52%，且出现 3 次硬止损和 5 次 timeout，尾部风险明显变大。 |
| Keltner 要不要恢复 | 不建议 | 恢复 Keltner 2.4 后收益降到 +410.05%，交易减少但回撤没改善，说明它主要漏掉趋势中段。 |
| 成交量和空头严格度 | 必须保留 | 去掉成交量或空头额外严格度都会显著降低收益、扩大回撤，说明它们在过滤低质量突破。 |
| 硬止损/移动止损/timeout | 历史未触发不代表没用 | 本样本内硬止损、trailing、timeout 都没触发；它们是尾部保护，不应因为历史没触发就删除。 |
| 仓位目标 | 收益弹性最大，风险也最大 | 0.022/0.020 可到 +885.43%，但回撤到 -19.93%，51 笔触达 3x cap；这是进攻分支，不是稳健默认。 |
