## 判断

| 主题 | 结论 |
| --- | --- |
| 收益提升来自哪里 | V2P 放宽通道和成交量过滤，略提高仓位，同时把 trailing 收紧，能多吃到一批有效突破，止盈笔数 45 -> 49。 |
| 风险点 | Train 收益低于 V2O，且 90天最低收益从 +10.59% 降到 +5.97%；说明它更依赖后半段行情。 |
| 是否直接替代 V2O | 不建议立刻替代。V2P 是强候选，但参数改动较多，应再做 30天滚动、手续费滑点加倍、最近样本外跟踪。 |
| 保守选择 | 如果只想小幅增强，最小改动候选更稳：只把 target_atr 0.013 -> 0.014，收益 +309.84%，回撤 -14.83%。 |
| 当前建议 | 主台账先保留 V2O；把 V2P 标记为高收益候选，下一轮做更严格鲁棒性测试后再决定是否记录正式版本。 |
