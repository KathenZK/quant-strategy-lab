# HYPE-EMA-TB-V35 4h RSI6 极值入场过滤诊断

日期：2026-07-17

## 结论

不建议把“开仓时 4h RSI6 已超跌或超买则不开单”加入 `HYPE-EMA-TB-V35`。

主口径把超跌/超买定义为 `RSI6 <= 20` 或 `RSI6 >= 80`，多空均禁止入场。完整路径回测中：

- V35 base：`+7067.61% / -27.26% / Sharpe 4.51 / 110 笔 / 胜率 77.27%`。
- 4h RSI6 `20/80` 过滤：`+477.72% / -27.03% / Sharpe 2.76 / 53 笔 / 胜率 71.70%`。
- 最终资金只保留 base 的 `8.06%`，最大回撤仅改善 `0.23pp`，没有形成有效风险交换。
- base 的 110 笔交易中，有 65 笔在入场时处于 `RSI6 <= 20` 或 `>= 80`；这些交易 53 胜，平均单笔 `+5.09%`，自身复合收益 `+1982.58%`。过滤掉的主要是 V35 依赖的强趋势延续单，而不是低质量噪音。

补测更窄的 `10/90` 禁入仍不成立：full `+4792.51% / -27.26% / Sharpe 4.36 / 100 笔 / 胜率 77.00%`。它完全没有改善 maxDD，胜率比 base 下降 `0.27pp`，最终资金只保留 `68.26%`。Base 中 13 笔 `10/90` 极值交易有 11 笔盈利，平均单笔 `+5.51%`。

`30/70` 宽口径虽然把 maxDD 降到 `-15.42%`，但交易只剩 19 笔、full 收益仅 `+168.49%`、最终资金只保留 base 的 `3.75%`；最近 1 个月零交易。这不是可接受的 V35 增强，而是基本关闭了趋势策略。

决定：不修改 V35，不登记新版本，不修改 live runner。该过滤只保留为已否决诊断。

## 规则与无前视时序

### RSI 定义

在由 15m 数据聚合出的 4h close 上计算 Wilder RSI：

```text
delta = close.diff()
gain = max(delta, 0)
loss = max(-delta, 0)
avg_gain = gain.ewm(alpha=1/6, adjust=False, min_periods=6).mean()
avg_loss = loss.ewm(alpha=1/6, adjust=False, min_periods=6).mean()
RSI6 = 100 - 100 / (1 + avg_gain / avg_loss)
```

4h K 线使用 `resample("4h", label="left", closed="left")`。RSI 计算后先 `shift(1)`，再向 15m 时间轴 `ffill`，因此任一 15m 时点只读取上一根已经完整收盘的 4h K。

### 入场时序

- V35 原规则：K0 收盘确认信号，完整跳过 K1，K2 open 入场。
- 新过滤在 K2 open 执行前读取当时最新的已收盘 4h RSI6。
- 主口径 `symmetric_20_80`：若 `RSI6 <= 20` 或 `RSI6 >= 80`，无论多空均不开单。
- 敏感性 `symmetric_10_90` 与 `symmetric_30_70`：边界分别改为 `10/90` 与 `30/70`。
- 方向性对照：多单只拦超买、空单只拦超跌。`20/80` 结果与对称过滤完全一致，说明 V35 的多头信号自然集中在高 RSI、空头信号自然集中在低 RSI。
- 除入场过滤外，V35 的信号、仓位、成本、funding、`5ATR TP / 7ATR SL`、ADX22 delayed3、384 根 timeout 均不变。

## 机制解释

V35 是强趋势突破/延续策略。多头要求 EMA、ADX、成交量与 1h DI 同向，空头要求更高 ADX 和成交量；当这些条件同时成立时，4h RSI6 进入高位或低位是趋势强度的自然结果。把传统均值回归语境中的“超买/超跌”直接当作趋势策略禁入条件，会把核心赢家当成反转风险过滤掉。

这也解释了两个现象：

1. `20/80` 对称和方向性过滤结果完全相同：样本里没有通过 V35 多头条件但因“超跌”被额外拦截的有效路径，也没有通过空头条件但因“超买”被额外拦截的有效路径。
2. `20/80` 几乎不改善 full maxDD：V35 的主要回撤并不能靠删除 RSI 极值入场解决，但长期复利高度依赖这些极值趋势单。
