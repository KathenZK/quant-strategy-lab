# HYPE-EMA-TB-V35.1 / V35.3 ADX14 替换诊断

日期：2026-07-21  
状态：`diagnostic only / not promoted / not live-ready`

## 结论

不能把 V35.1 或 V35.3 的 `15m ADX28` 直接替换成 `ADX14`。

在保持多头 `ADX>=28`、空头 `ADX>=36`、指标退出 `ADX<22 delayed3` 不变时：

- V35.1 full 从 `+8047.47% / -27.26% MaxDD` 变为 `+38.70% / -72.48%`；
- V35.3 full 从 `+10017.59% / -22.88%` 变为 `-33.65% / -83.10%`。

主要问题是 ADX14 入场过滤过于敏感，放入大量低质量交易；在 V35.3 中将 ADX14 只用于退出同样明显劣化。

本轮没有重扫 ADX14 的入场/退出阈值，因此结论只是否决“同阈值直接替换”，不等于证明任何重新设计的 ADX14 机制都无效。

## 测试口径

- 基准：`HYPE-EMA-TB-V35.1` 与 `HYPE-EMA-TB-V35.3`。
- 数据：Binance USD-M HYPEUSDT perpetual `15m`，`2025-05-30 10:30 UTC` 至 `2026-07-20 08:15 UTC`，39,928 根已闭合 K。
- 数据质量：缺口、重复、关键空值、OHLC 违规、raw/normalized 差异均为 0；UTC 与 funding 对齐检查通过。
- 成本：每次实际 fill 按 allocation 收取 `0.00085`，计入 Binance funding。
- 唯一正式变更：15m ADX/DI Wilder 窗口 `28 -> 14`；1h `ADX21/DI21` 不变。
- 固定阈值：多头 `ADX>=28`、空头 `ADX>=36`、指标退出 `ADX<22` 连续 3 根。
- 其余规则不变：两版均为 K0 信号/K2 open 入场、TP5、timeout384、cooldown0；V35.1 保持 SL7 且无分批，V35.3 保持 long SL6.75、short SL5.7 与空头 MFE4.4 减仓 75%。
- 标准近期分片仅用于审计，没有参与选参。

## 归因

1. **主要破坏来自入场。** V35.1 完整替换后交易数从 112 增至 295，只有 45 个 entry timestamp + direction 签名重合；V35.3 的 ADX14 仅入场归因则增至 342 笔，收益几乎归零且 MaxDD 达到 `-67.80%`。
2. **空头过滤失效尤其明显。** 完整替换后空单从 27 增至 142；更快的 ADX14 更容易短暂越过 `36`，不能沿用 ADX28 的门槛解释为同等趋势强度。
3. **换手成本显著增加。** 累计交易成本统计从基准 `52.78%` 增至 `131.70%`，约为 2.50 倍，但成本不是唯一原因：胜率同时从 `79.65%` 降到 `54.55%`。
4. **ADX14 退出也不兼容。** 只替换退出 ADX 时，完整收益仍减少约 `5327.63pp`，MaxDD 恶化 `9.51pp`；虽然 112 个基准 entry 签名仍能匹配，但不同的指标退出时点改变了后续占仓和再入场路径。

## 决策

- V35.1 与 V35.3 继续使用 `15m ADX28/DI28`，不修改研究规格或 runner。
- 不登记 ADX14 主腿变体，不提升状态。
- 若继续研究 ADX14，应作为独立参数化诊断重新扫描多头、空头和退出阈值，并做冻结后 OOS；不能把 ADX28 的 `28/36/22` 原样搬到 ADX14。
