# V39.2 静态硬止损 ATR 扫描

> 状态：`diagnostic only / V39.2 unchanged / not promoted / not live-ready`
>
> 结论：硬止损不能大幅收窄。`4–6.5ATR` 整体显著弱于已登记的 `7ATR`；`6.75–6.95ATR` 在当前样本中严格改善 full 收益、最大回撤与 Sharpe，其中 `6.75ATR` 最好，但它只把未触及 3x cap 时的一次完整止损从多头/空头约 `-14.0%/-15.4%` 降到 `-13.5%/-14.85%`，不能根本改变盈亏比，而且 `6.70 -> 6.75ATR` 存在明显路径断点。因此只把 `6.75ATR` 保留为 shadow 诊断值，不修改 V39.2。

## 测试口径

- 市场：Binance USD-M 永续，`HYPE/USDT:USDT`，`15m`。
- 数据：`2025-05-30 10:30 UTC` 至 `2026-07-17 08:45 UTC`，共 `39,642` 根已闭合 K 线。
- 质量检查：缺口 `0`、重复 `0`、关键字段空值 `0`、OHLC 非法行 `0`；raw/normalized 全量对齐差异 `0`。
- 成本：每次 fill `0.00085`，含既有手续费与 `4 bps` adverse slippage 合并口径；计入 Binance funding。
- 基准：已登记 `HYPE-EMA-TB-V39.2`，`long_vol_min=0.25`、多空 target ATR `0.020/0.022`、cooldown1、`TP5ATR / SL7ATR`。
- 唯一变量：从开仓起生效的 entry-anchored 静态硬止损距离。
- 其它规则不变：K0 close 信号、K2 open 入场、ADX22 delayed3、`MFE>=1.5ATR` 后关闭指标退出、384 根 timeout、3.0x cap。
- 同 bar 同时触发 stop/TP 时采用 stop-first；`6.75ATR` 另做 gap-open 对照，equity 最大差异为 `0`。
- 最近分片仅用于审计，不用于选择。

## 为什么 6.75ATR 看起来更好

两组共有 `109` 个相同 entry/direction 的已平交易，`6.75ATR` 另多出 `1` 笔交易。主要变化有两类：

1. 原基准的 `14` 笔 stop loss 均以更近的价格退出，每笔少亏约 `0.28–0.65pp`；
2. `2025-08-27 04:15 UTC` 多单在 `6.75ATR` 下提前止损，随后 cooldown1 结束后于 `09:15 UTC` 重入并 TP：
   - `7ATR` 原路径：单笔 indicator exit，约 `-6.19%`；
   - `6.75ATR` 新路径：先约 `-13.33%` 止损，再约 `+9.90%` TP，复合约 `-4.75%`。

第二项主要依赖“提前退出后恰好获得一次成功重入”，该链条相对原路径只改善约 `1.53%`，却造成 `6.70/6.75ATR` 之间的离散跳变。它不是稳定的“更窄止损必然更优”证据。

## 盈亏比解释与决定

V39.2 使用 target ATR sizing。忽略手续费、funding 与 3x cap 时：

- `SL7 / TP5`：多头约 `-14% / +10%`，空头约 `-15.4% / +11%`；一笔完整止损约需 `1.4` 笔 TP 毛利润恢复；
- `SL6.75 / TP5`：多头约 `-13.5% / +10%`，空头约 `-14.85% / +11%`；恢复比只降到 `1.35`。

若把止损明显缩到能接近 `1:1` 的 `5ATR`，full 收益降至 `+4245.55%`、MaxDD 恶化到 `-29.42%`、胜率降至 `70.97%`，原因是大量正常趋势回撤被提前止损，并改变后续入场路径。

因此：

- V39.2 继续保持 `7ATR`，不登记新版本、不修改 runner；
- `6.75ATR` 仅作为温和 shadow 候选，需独立 OOS/交叉验证后才能讨论版本登记；
- 如果目标是实质降低一次亏损的账户冲击，应优先研究降低 target ATR / allocation cap 的风险预算，而不是把结构止损压到 `5–6ATR`。该 sizing 方向不属于本次扫描结论。
