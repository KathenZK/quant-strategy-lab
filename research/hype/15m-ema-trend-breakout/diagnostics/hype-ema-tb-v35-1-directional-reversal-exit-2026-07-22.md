# HYPE-EMA-TB-V35.1 方向性反转退出诊断（2026-07-22）

## 结论

**本轮不修改 V35.1、不登记新版本、不修改或发布 runner。**

方向反转退出能在反事实中减轻 `2026-07-21 05:45 UTC` 多单的损失，但没有证明它能普遍修复 V35.1 的止损交易：

- 宽松的 `15m DI` 反转会频繁误杀历史交易，full 收益和 MaxDD 都恶化。
- `15m DI + ADX 上升` 的严格规则在目标亏损发生前最多只触发 1 次，而且那次比原 `indicator_exit` 更差；更严格的 3 根确认在目标事件前 0 次触发。
- `1h DI` 单根确认在目标事件前 0 次触发；它的全部样本改善只来自当前已知亏损。
- 所有变体都没有提前挽救任何一笔当前事件之前的 V35.1 `stop_loss`。

因此，本次结果证明的是“该规则可以解释并截断当前案例”，不是“该规则已经具有可部署的样本外泛化能力”。继续围绕这笔亏损调参会形成明显的 post-hoc 过拟合。

## 数据与执行口径

- 市场：Binance USD-M Futures `HYPEUSDT` perpetual。
- 周期：`15m`。
- 最终闭合 K 范围：`2025-05-30 10:30 UTC` 至 `2026-07-22 02:45 UTC`，共 `40,098` 根。
- 数据质量：缺口 0、重复 0、关键空值 0、OHLC 违规 0、raw/normalized 不一致 0；funding `2,505` 条、空值 0。
- 本诊断直接以 Binance server time 过滤最终闭合 K，未使用生产 runner 的 `bar_close_delay_seconds=0.01` provisional K；该生产数据最终性 blocker 仍未在本轮处理。
- 入场、仓位、`TP5 / SL7`、原 `ADX28<22 delayed3`、`MFE>=1.5ATR` 后禁用 soft exit、`timeout384` 均保持 V35.1 不变。
- 新退出只在 `MFE<1.5ATR` 且持仓按收盘价已亏损时允许触发；收盘确认，下一根 open 平仓，同根仍先执行硬 SL/TP。
- 成本：每次成交按 allocation 收取 `0.00085`，即 `0.00045 fee + 4bps adverse slippage`，另计 Binance funding。
- 标准 `1d/7d/1m/3m/6m/1y` 分片均锚定数据末端；本轮全样本和近期分片都参与诊断，不是独立 OOS。
- 自定义 V35.1 baseline 与 canonical engine 逐根权益最大差为 `0`。

## 测试规则

所有规则均做多空镜像：

1. `di15_cN`：持仓亏损且 15m 方向 DI 反转，连续 `N=1/2/3` 根。
2. `di15_adxrise_cN`：在 1 的基础上要求当根 `ADX28 > 前一根 ADX28`，连续 `N=1/2/3` 根。
3. `di15_adxrise_c2_a1/a2`：在 2 根确认基础上再要求至少亏损 `1ATR / 2ATR`。
4. `di1h_cN`：持仓亏损且上一根已完成 1h 的方向 DI 反转，连续 `N=1/2` 根。

其中多头方向反转为 `-DI > +DI`，空头镜像为 `+DI > -DI`。

## “救止损”与“误杀盈利”拆解

### 仅用 15m DI：否决

- 1 根确认在 12 笔可与 baseline 精确对齐的方向退出中，baseline 结局为 `8 indicator_exit / 3 take_profit / 1 stop_loss`；4 笔改善、8 笔恶化，匹配交易收益合计变化 `-32.11pp`。
- 2 根确认有 `7 indicator_exit / 2 take_profit / 1 stop_loss`；4 笔改善、6 笔恶化，合计变化 `-24.79pp`。
- 3 根确认仍误杀 2 笔 baseline TP，且 full 最终权益只保留 baseline 的 `62.33%`。
- 上述唯一被改写的 baseline `stop_loss` 都是本次已知的 `2026-07-21` 亏损，不是更早的独立案例。

结论：`DI` 反转本身过于敏感，虽然最早把当前亏损截到约 `-1.8%`，但长期代价不可接受。

### 15m DI + ADX 上升：有表面改善，但证据不足

- 1 根和 2 根确认各触发 2 笔：当前 `stop_loss` 得到改善，但 `2026-07-06` 的原 `indicator_exit` 被提前后反而更差。
- 在当前亏损入场前，1 根/2 根版本最终权益分别只保留 baseline 的 `96.61% / 96.91%`，MaxDD 分别从 `-27.26%` 恶化到 `-29.72% / -29.51%`。
- 3 根确认在当前亏损入场前 0 次触发，历史路径与 baseline 完全一致；full 的全部 `+427.68pp` 收益差及当前损失减少 `5.26pp` 都来自这一次已知事件。

结论：2 根确认并未通过历史反事实；3 根确认是“只命中目标事故”的 post-hoc 规则，不能据此晋升。

### 1h DI：太晚且没有独立样本

- 1 根确认只在当前事件触发，下一根 open 为 `2026-07-21 17:15 UTC @ 61.680`，交易回报约 `-6.63%`。
- 同一根 15m K 内硬 SL7 也已触发；方向退出之所以显示较优，仅因为回测对 soft exit 使用 next-open，而硬止损使用预设 stop 价。这不是可依赖的稳定时间优势。
- 2 根确认来不及在硬止损前生效，结果与 baseline 完全相同。

结论：1h DI 对这个风险场景反应过慢。

## 当前亏损反事实

研究 baseline 以最终闭合数据复现：

- 入场：`2026-07-21 05:45 UTC @ 63.031`。
- `entry ATR672 = 0.323583`，MFE `1.267ATR`。
- baseline：`2026-07-21 17:15 UTC` 命中 `SL7 @ 60.765917`，交易回报 `-10.79%`。

代表性方向退出：

- `15m DI c1`：`11:00 UTC` 确认、`11:15 UTC @ 62.708` 平仓，`-1.80%`。
- `15m DI + ADX rising c2`：`14:30 UTC` 确认、`14:45 UTC @ 62.170` 平仓，`-4.36%`。
- `15m DI + ADX rising c3`：`14:45 UTC` 确认、`15:00 UTC @ 61.916` 平仓，`-5.53%`。
- `1h DI c1`：`17:00 UTC` 确认、`17:15 UTC @ 61.680` 平仓，`-6.63%`。

生产实际交易约 `-10.82%`，与最终闭合 K 的 baseline `-10.79%` 接近；差异来自实际入场、成交和费用，不改变本轮方向退出结论。

## 决策与后续

1. V35.1 保持原退出状态机；不把任何方向退出写入 `hype-trend` 或 `quant-runner`。
2. 不继续对这笔已知亏损做阈值微调。若保留研究观察，只记录冻结的 `MFE<1.5ATR + 持仓亏损 + 15m opposite DI + ADX rising 连续 3 根` shadow 事件，等待新的时间前推样本。
3. 新增独立样本至少要回答：是否能提前处理此前未见的 SL、是否误杀本来会 TP 的交易、是否在 next-open 和真实滑点下仍改善。
4. 生产 `bar_close_delay_seconds=0.01` 的最终闭合 K blocker 与本研究规则无关，仍应单独修复和验证。
