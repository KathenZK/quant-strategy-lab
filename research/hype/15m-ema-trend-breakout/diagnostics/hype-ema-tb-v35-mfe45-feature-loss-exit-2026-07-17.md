# V35 `MFE>=4.5ATR` 后方向特征失效退出版诊断

> 状态：`diagnostic only / V35 unchanged / not promoted`
>
> 结论：否决“多空达到 `4.5ATR` 后，15m EMA、1h EMA、ADX、量能任一方向特征失效即退出”。该规则能改善两笔近期空单回吐，但 full 收益从 `+7708.65%` 降至 `+5257.38%`，MaxDD 从 `-27.26%` 恶化到 `-30.49%`，Sharpe 从 `4.56` 降至 `4.25`；32 次条件退出中，30 次可与 V35 相同 entry 对齐，其中 29 次基准最终为 TP。

## 测试规则

仅在本笔历史 MFE 已达到 `4.5ATR` 后，逐根检查最新已完成 `15m` K 的四项方向特征。

多单要求全部保持：

1. 15m `EMA96-EMA384 > 0`；
2. 1h `EMA24-EMA96 > 0`；
3. 15m `ADX28 >= 28`；
4. `volume_surge >= 0.25`。

空单要求全部保持：

1. 15m `EMA96-EMA384 < 0`；
2. 1h `EMA24-EMA96 < 0`；
3. 15m `ADX28 >= 36`；
4. `volume_surge >= 0.50`。

任一条件失效，则在该 `15m` 收盘确认，下一根 open 平仓。原始盘中 `TP5 / SL7` 优先，不允许在触发 bar 的 close 回看式成交。

需要特别说明：V35 原始多头入场使用 1h `ADX/DI`，不使用 1h EMA；本实验按用户指定，额外把 `1h EMA>0` 作为多头持仓条件。量能口径为 `volume_surge = volume / rolling_mean(volume, 192) - 1`，只使用最近已收盘 K。

- 市场：Binance USD-M perpetual，`HYPE/USDT:USDT`，`15m`。
- 数据：`2025-05-30 10:30 UTC` 至 `2026-07-17 08:45 UTC`，`39,642` 根已闭合 K。
- 数据质量：缺口、重复、关键空值、OHLC 违规、raw/normalized 差异均为 `0`。

- 成本：每次 fill `0.00085`。

- 其它退出：V35 原始 ADX22 delayed3、`MFE>=1.5ATR` 后关闭指标退出、384 根 timeout 全部保持。
- 自定义引擎与 canonical V35 baseline equity 最大差异为 `0`。

## 触发归因

共发生 `32` 次条件退出：

- 多单 `20` 次，空单 `12` 次；
- 仅 ADX 失效 `19` 次；
- 仅量能失效 `9` 次；
- ADX 与量能同时失效 `4` 次；
- 15m EMA 或 1h EMA 单独触发 `0` 次。

因此，这套四项规则在历史样本中实际上退化成“高 MFE 后 ADX/量能退出”。30 次可与 V35 相同 entry 对齐的事件中：

- `29` 笔 V35 最终为 TP；
- `1` 笔 V35 最终为 SL；
- 条件退出平均单笔约 `+6.06%`，对应 V35 路径平均约 `+7.58%`。

这解释了 TP 次数从 `84` 降到 `57`：它确实救回一个大亏损，但更频繁地截断了最终能够达到 TP5 的趋势单。

## 近期交易路径

### `2026-07-13 14:45 UTC` 空单

- V35：MFE `4.829929ATR` 后最终 SL，约 `-11.49%`；
- 条件版：因量能失效，于 `2026-07-13 22:15 UTC` 下一根 open 退出，约 `+4.49%`。

该案例得到明显改善。

### `2026-07-16 23:00 UTC` 空单

- V35：最终 TP5，约 `+7.33%`；
- 条件版：达到 `4.508580ATR` 后量能失效，于 `2026-07-17 00:00 UTC` 退出，约 `+5.64%`。

该案例属于被提前截断的正常 TP。

### `2026-07-17 02:00 UTC` 空单

- V35：截至数据终点仍 open，MFE `4.990884ATR`，已回吐到约 `1.52ATR`；
- 条件版：直到 `08:15 UTC` 才因量能失效，`08:30 UTC` open 退出，约 `+2.31%`。

规则能避免继续暴露，但没有锁住接近 TP5 的大部分利润：从 `4.99ATR` 峰值回吐后才触发，明显慢于固定 `TP4.8`。

## 决定

- V35 保持原始退出规则，不登记新版本、不修改 live runner；
- 不采用本轮双向四特征任一失效退出；
- 该结果再次说明 ADX 和单根量能是滞后/易失的持仓退出条件：它们能识别趋势降温，但无法稳定区分“正常喘息后 TP”与“近 TP 后彻底反转”；
- 若目标是专门解决 `4.8–5ATR` 临门回吐，固定 TP 或价格型 profit floor 比等待 ADX/量能失效更直接，但仍需接受收益让渡和再入场路径变化。
