# HYPE-EMA-TB V35 分阶段提前入场诊断（2026-07-17）

> 状态：`explore diagnostic candidate / not registered / not promoted / not live-ready`
>
> 结论：找到一个在当前完整窗口中同时高于 V35 收益、低于 V35 回撤且不提高 3x 最大 allocation 的分阶段候选；但提前腿只有 28 笔，筛选条件来自同一历史窗口，尚不能登记或推进 promotion。

## 研究问题

目标不是把 V35 主仓机械地从 K2 提前到 K1，而是在不改变 V35 核心趋势确认的前提下：

1. 用小仓 early-long 试仓提前捕捉趋势；
2. 主腿确认时在同一 open 完成试仓平仓和主腿开仓；
3. 用 V38 的极窄利润保护降低 V35 的利润回吐；
4. 要求 full 收益、MaxDD、Sharpe 同时不劣于 V35，且组合最大 allocation 仍为 3.0。

## 数据、成本与质量

- 市场：Binance USD-M `HYPEUSDT` perpetual。
- 周期：`15m`；所有时间为 UTC。
- 规范化数据范围：`2025-05-30 10:30` 至 `2026-07-16 15:30`；暖机后回测范围为 `2025-06-16 02:30` 至 `2026-07-16 15:30`。
- 数据源：data lake，规范化记录的来源为 `binance_futures_kline_api`。
- 质量检查：`39,573` 根，重复时间戳 `0`、缺失 15m bar `0`、关键字段空值 `0`、无效 OHLC `0`、未闭合 bar `0`；raw/normalized `39,573` 根全量对齐。
- 成本：沿用本家族冻结口径，每次 fill 收取 `0.00085 × allocation`；Binance funding 按 15m bar 对齐计入。
- 近期分片只用于审计；提前信号筛选与仓位搜索使用了完整历史，因此结果属于样本内候选。

## 候选状态机

### 主腿

- V35 原有信号、K2 open、ATR sizing、TP5/SL7、ADX delayed exit 与 timeout 均不变。
- 叠加已登记观察版 V38 的窄利润保护：当已完成 bar 的 `MFE >= 4.75ATR` 时，把下一根开始生效的保护位提高至 `entry + 4.25ATR`；不回看当前 bar 触发前的 high/low。

### early-long 试仓

基础条件为 V37 canonical early-long：

- `EMA96 - EMA384 > 0`；
- `volume_surge >= 0.25`；
- 已完成 1h bar 的 `ADX21 > 18` 且 `+DI21 > -DI21`；
- `ADX28 < 28`，即 V35 主腿尚未完成 ADX 确认；
- `ADX14 >= 35` 且比前一根上升；
- `+DI14 > -DI14`。

本轮平衡过滤再要求：

- `+DI14 - -DI14 >= 22`；
- `ADX14 - ADX14.shift(3) >= 2`；
- `close / close.shift(16) - 1 <= 5%`，避免四小时内已经过度拉升后才试仓。

执行与风险：

- K0 收盘确认，K2 open 入场；
- `target_atr_pct = 0.008`，`max_allocation = 1.0`；
- `TP = 4ATR`、`SL = 5ATR`；
- `ADX14 < 22` 后在下一根 open 弱势退出；
- 主腿持仓期间不允许新开试仓；
- 若 V38 主腿产生入场，试仓在同一个 K2 open 先平仓，主腿再开仓；
- 主腿与试仓无持仓区间重叠，组合最大 allocation 保持 `3.0`。

同 bar TP/SL 继续采用 stop-first；移交 bar 在 open 完成移交，不再使用该 bar 的试仓 TP/SL。

收益提升不是来自抬高最大杠杆。代价是组合交易数和累计成本上升，胜率也略降；改善来自提前腿的正期望与 V38 对主腿回吐的削减，而不是“每项指标都提高”。

提前腿 standalone 为 `+19.25% / -5.15% / Sharpe 1.90 / 28笔 / 胜率64.29%`。其中 `12` 笔在主腿确认时移交，领先主腿入场的中位数为 `4` 根 15m bar（1 小时），范围为 `1–21` 根；持仓区间重叠审计为 `0`。

## 稳定性检查

### 执行延迟

| early-leg 执行 | full return | MaxDD | Sharpe | 是否同时胜过 V35 |
| --- | ---: | ---: | ---: | --- |
| K1 open | +7262.33% | -23.46% | 4.51 | 是 |
| K2 open | +7530.59% | -23.46% | 4.55 | 是 |
| K3 open | +7220.59% | -23.46% | 4.51 | 是 |

K2 是本轮最佳点，但 K1/K3 没有发生断崖，说明结果不是只靠一个 15m 成交点成立。

### 邻域阈值

分别只改动 `DI gap 20/24`、`ADX14 三根增量 1/3`、四小时涨幅上限 `4%/6%`。六个邻域版本全部同时高于 V35 full return 且低于 V35 MaxDD：

- full return 约 `+7219%` 至 `+7487%`；
- MaxDD 为 `-25.53%` 至 `-23.46%`；
- Sharpe 为 `4.50` 至 `4.54`。

宽松到四小时涨幅上限 `6%` 后回撤恶化至 `-25.53%`，支持保留“避免已过度拉升”的约束，但当前 `5%` 仍是样本内选择。

### 前后半段

- `2025-06-16` 至 `2025-12-31`：V35 `+377.86% / -23.46%`，候选 `+394.12% / -23.46%`。
- `2026-01-01` 至 `2026-07-16`：V35 `+1399.93% / -27.26%`，候选 `+1444.29% / -22.58%`。

两个自然时间段的收益均未退化，但前半段只提高收益、未改善回撤；主要回撤改善来自后半段。

## 判断

当前证据支持回答“能否从 V35 微调出更早入场、收益更高、回撤更低的结构”：**在本次历史窗口内可以，且分阶段候选没有靠提高最大 allocation 达成。**

但它暂时只能作为后续验证候选，不能登记新版本，原因是：

1. early-long 仅 `28` 笔，主腿移交仅 `12` 笔；
2. `DI gap / ADX 增量 / 4h 涨幅` 来自同一窗口筛选；
3. 尚未完成正式 walk-forward/CPCV、Monte Carlo、成本压力、缺 bar/restart 状态恢复与 runner parity；
4. 当前 V35 是 legacy live，V38 与本候选都没有获得替换 live 主腿的授权。

下一决策门应是冻结当前参数后做不再调参的 OOS/交叉验证与成本压力；若失败，保留 V35，不继续在同一窗口微调阈值。
