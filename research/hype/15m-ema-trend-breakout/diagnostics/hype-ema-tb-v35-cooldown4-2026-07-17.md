# HYPE-EMA-TB-V35 平仓后冷却 4 根诊断

日期：2026-07-17

## 结论

不建议给 `HYPE-EMA-TB-V35` 加入平仓后 4 根 15m K 冷却。

- V35 base：`+7067.61% / -27.26% / Sharpe 4.51 / 110 笔 / 胜率 77.27%`。
- V35 + cooldown4：`+3146.64% / -36.47% / Sharpe 3.92 / 98 笔 / 胜率 76.53%`。
- 冷却后最终资金只保留 base 的 `45.30%`，最大回撤反而恶化 `9.21pp`，胜率下降 `0.74pp`。
- 与上一轮 4h RSI6 `10/90` 禁入叠加也不成立：`+2999.81% / -30.62% / Sharpe 4.13 / 89 笔 / 胜率 77.53%`。胜率仅比 base 高 `0.26pp`，但收益、回撤与 Sharpe 全面更差。

决定：不修改 V35，不登记新版本，不修改 live runner。

## 冷却口径

若交易在 15m bar `E` 平仓：

```text
E+1、E+2、E+3、E+4：禁止开仓
E+5 open：最早允许重新开仓
```

冷却适用于所有退出原因，包括 `take_profit`、`stop_loss`、`indicator_exit` 和 timeout。除冷却外，V35 的信号、K0/K1/K2 入场时序、仓位、`5ATR TP / 7ATR SL`、ADX22 delayed3、384 根 timeout、成本与 funding 均不变。

为了覆盖本轮对话的连续假设，另外测试 `4h RSI6 <=10 或 >=90 禁入 + cooldown4`；RSI 只使用 K2 open 时最新已完整收盘的 4h K，无前视。
