# HYPE-EMA-TB-V35.3 空头极端放量绕过 ADX 诊断

## 结论

否决“`EMA spread < 0` 且成交量达到 MA192 的 3 倍时，不再检查空头 `ADX28 >= 36`”。

该规则确实会更早抓到 `2026-07-22` 当前这段下跌，但历史上会把大量单根放量、尚未形成持续趋势的波动误判为空头趋势。全样本收益从 `+9553.28%` 降至 `+472.51%`，MaxDD 从 `-22.88%` 扩大到 `-53.41%`，Sharpe 从 `4.80` 降至 `1.86`。不修改 V35.3、不登记版本、不修改 runner。

## 规则口径

- 基准：V35.3，空头正常入场仍要求 `EMA spread < 0`、`ADX28 >= 36`、`volume_surge >= 0.50`。
- 主测试：保留正常路径，并增加旁路：`EMA spread < 0` 且 `volume / volume_MA192 >= 3.0` 时允许空头，不检查 ADX。
- 当前特征里的 `volume_surge = volume / MA192 - 1`，所以“成交量为均量 3 倍”对应 `volume_surge >= 2.0`，不是 `3.0`。
- 敏感性：无 ADX 的 `2x/4x/5x`，以及 `3x + ADX floor 28/32/34`。
- 执行：K0 收盘确认，完整跳过 K1，K2 开盘成交；stop-first；V35.3 空头 MFE4.4ATR 减仓 75%，剩余 25% 使用 TP5/SL5.7。

## 解释与决定

极端成交量只能说明交易活跃度和冲击强度，不能证明下跌方向已经形成可持续趋势；它也可能来自清算、吸收、短时恐慌或随后反转。ADX 虽然滞后，但在本策略里承担的是“持续趋势形成”门禁，不能由单根成交量直接替代。

决定保持 V35.3 空头 `ADX28 >= 36` 不变，不采用 `3x` 成交量旁路，也不把 `ADX34` 敏感性档位升级为候选。若要继续研究，应等待时间前推样本，并把“ADX 正在快速上升”作为独立机制提出，而不是针对本笔行情放宽现有版本。
