# V35 分批止盈诊断

> 状态：`diagnostic only / shadow candidate / V35 unchanged / not promoted`
>
> 结论：多空统一分批和只对多单分批均不适合 V35；但“仅空单在 `4.2ATR` 平掉 `75%`，剩余 `25%` 继续原始 `TP5/SL7`”在当前样本同时提高收益、Sharpe、胜率并降低回撤。它把两笔已达到高 MFE 的空头 SL 改为小幅盈利，但结论直接受近期回吐事件启发，且只有 `26` 笔空单，暂时只能作为待 OOS 的 shadow，不能据此修改 V35 live runner。

## 测试规则

本次只测试单级 scale-out：

1. 以 entry price 和 entry `ATR672` 固定分批价；
2. 盘中触及分批价时执行一次 reduce-only 减仓；
3. 剩余仓位继续 V35 原始 `TP5 / SL7 / ADX22 delayed3 / timeout384`；
4. 分批不结束本笔策略持仓，不增加交易笔数、不允许重新入场、不启动 cooldown；
5. 同一根 K 同时触发止损和有利价格时按 stop-first；未触发止损而同时触及分批价和 TP5 时，先分批、再平剩余仓位；
6. 入场、分批、最终退出均按实际成交 allocation 计成本，funding 只作用于剩余仓位。

扫描范围：

- 多空统一：`3.5 / 4.0 / 4.5ATR × 25% / 33.3% / 50%`；
- 只做多：`4.0ATR × 25% / 33.3% / 50%`；
- 只做空：宽扫描 `3.5 / 4.0 / 4.5ATR × 25% / 33.3% / 50%`，并在有效邻域补测 `4.0 / 4.2 / 4.4ATR × 66.7% / 75%`。

## 数据与执行口径

- 市场：Binance USD-M perpetual，`HYPE/USDT:USDT`，`15m`。
- 数据：`2025-05-30 10:30 UTC` 至 `2026-07-17 08:45 UTC`，`39,642` 根已闭合 K。
- 数据质量：缺口、重复、关键空值、OHLC 违规、raw/normalized 差异均为 `0`。
- Funding：Binance funding，对齐实际剩余仓位。
- 成本：每次 fill `0.00085`。
- 入场：K0 close 信号、K2 open 成交，entry ATR 使用已完成 K1 的 `ATR672`。
- 自定义分批引擎在关闭分批时与 canonical V35 的 equity 最大差异为 `0`。

## 为什么只做空有效

V35 共 `85` 笔多单、`26` 笔空单。候选规则发生 `23` 次空头分批：`22` 笔已结束，其中 `20` 笔最终 TP、`2` 笔最终 SL；另有 `1` 笔截至数据末端仍持仓。

只做空 `4.2ATR / 75%` 的静态收益几何为：

- 分批后最终 TP：`75% × 4.2 + 25% × 5 = 4.4ATR`，相对原 TP5 让渡 `12%` 毛利润；
- 分批后最终 SL：`75% × 4.2 + 25% × (-7) = +1.4ATR`，高 MFE 回吐不再成为整笔大亏；
- 未达到 `4.2ATR` 的空单仍承担完整 SL7。

它实际改写了两笔空头回吐：

| Entry UTC | V35 结果 | `4.2ATR / 75%` 结果 |
| --- | ---: | ---: |
| 2026-02-23 17:00 | -12.70% | +2.23% |
| 2026-07-13 14:45 | -11.49% | +1.83% |

空头 TP 平均单笔从 `+8.62%` 降到 `+7.52%`，但空头 SL 标签交易的均值从 `-11.61%` 改善到 `-5.96%`。全策略平均 TP / 平均 SL 的恢复需求从 `1.35` 笔降到 `1.19` 笔；胜率增加 `1.80pp`，是因为上述两笔最终仍以 `stop_loss` 退出的交易在计入分批后转为正收益。

多单分批相反：`4ATR` 共触发 `65` 次，主要削减原本会到 TP5 的赢家，却没有覆盖足够多的高 MFE 多头 SL，因此收益和 MaxDD同时恶化。多空统一规则的回撤下降主要来自空头腿，而收益被多头腿的频繁减仓拖累。

## 判断与下一门禁

这次结果说明分批止盈本身不是普遍解，方向差异非常大：

- 多空统一：降低回撤，但明显牺牲长期收益；
- 只做多：收益和回撤同时变差；
- 只做空：当前样本存在有效结构，尤其能处理高 MFE 后回吐到 SL 的尾部事件。

但该结构是看到 `2026-07-13` 和 `2026-07-17` 回吐后提出，属于 post-hoc 研究；`26` 笔空单中只有 `5` 笔 SL，收益提升主要由其中 `2` 笔贡献。决定：

1. V35 保持原规则，不登记新版本、不修改 live runner；
2. 暂存 `short MFE4.2ATR -> reduce 75%` 为 shadow candidate；
3. 若要 promotion，先固定该参数并做时间前推 OOS、walk-forward/CPCV、成本滑点压力和真实 reduce-only 部分成交审计。
