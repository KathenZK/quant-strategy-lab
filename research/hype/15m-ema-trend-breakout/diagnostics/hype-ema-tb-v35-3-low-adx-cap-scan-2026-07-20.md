# HYPE-EMA-TB-V35.3 低 ADX 降仓扫描

日期：2026-07-20  
状态：diagnostic only；V35.3 保持 `registered / not promoted / not live-ready`

## 机制解释

低 ADX 降仓不删除信号、不改变 TP/SL，也不改变最终退出状态机。它只在 K0 信号收盘时读取 V35.3 已使用的 `ADX28`：

```text
raw_allocation = target_atr_pct / entry_atr_pct
if ADX28 < threshold:
    allocation = min(raw_allocation, low_adx_cap)
else:
    allocation = min(raw_allocation, 3.0)
```

多头入场门槛为 `ADX28 >= 28`，空头为 `ADX28 >= 36`。因此 `ADX < 35` overlay 实际只影响 `28 <= ADX < 35` 的多头；空头不会被该阈值降仓。它表达的不是“低 ADX 不交易”，而是“趋势强度刚过最低门槛时仍参与，但少下仓”。

它在旧 V35 上是“牺牲长期复利、温和改善近期回撤”的 defensive overlay，不是 full MaxDD 修复。

## 结论

- 低 ADX 降仓的优点：不改变交易路径、容易实盘实现、能直接降低部分弱趋势入场的名义风险。
- 缺点：V35.3 的很多长期赢家同样来自 `ADX 28–35`，所以对这些交易降仓会显著损失复利。
- 旧 V35 的 `ADX<35 cap2.5` 不能直接视为 V35.3 的最佳值；当前 V35.3 上它只保留 80.63% 最终权益，且不改善 full MaxDD。
- 若只作为防守 shadow，当前更合理的是 `ADX<35 cap2.75`，而不是 cap2.5；但它仍未达到修改 V35.3 的证据标准。

因此本轮不修改 V35.3、不登记新版本、不修改 runner。若用户真正关注的是单笔账户风险，按方向设置固定 risk-budget sizing 比 ADX cap 更直接；低 ADX cap 更适合作为市场状态 overlay，而不是基础仓位规则。
