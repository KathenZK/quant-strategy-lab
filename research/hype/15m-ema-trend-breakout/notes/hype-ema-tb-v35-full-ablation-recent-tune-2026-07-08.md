# HYPE-EMA-TB-V35 全参数消融与最近 90 天微调

日期：2026-07-08

## 结论

对 V35 的 24 个参数做了逐项消融（62 个变体，每次只动一个参数，含"移除该过滤器"的结构性消融），然后围绕有效方向跑了 66 组微调网格，最后对两个候选做标准分片验证。

三个核心发现：

1. **V35 有两个回测等价的无效项**：`max_hold_bars=384` timeout（样本内 0 触发，移除后结果逐字节一致，但实盘保留为兜底）和空头 1h EMA 确认（与空头 `ema_spread<0` 互为备份，单独移除任一个结果完全一致，但两个都移除会严重劣化）。
2. **V35 大部分参数处在尖峰上，不能动**：`adx_window=28`、`long_adx_min=28`、`adx_exit=22`、`hard_stop_atr=7`、`atr_window=672`、`disable_after_mfe_atr=1.5`、`volume_window=192` 任何方向的偏移都显著劣化，多数直接把 full 收益砍半以上。
3. **找到两个改进候选**：`v35_tuned_mild`（全面严格优于 base）和 `v35_tuned_recent3m`（最近 90 天收益/胜率/回撤三项全部改善，但牺牲 6m/1y/full）。

## 诚实声明（选参口径）

- 最近 90/30 天窗口在微调阶段**直接参与选参**；标准 `1d/7d/1m/3m/6m/1y` 分片仅在最终验证阶段使用。
- 最近 90 天样本只有 34-35 笔交易，胜率差异在这个样本量下不具备强统计意义。
- `v35_tuned_recent3m` 移除了多头 `ema_spread>0` 过滤，这改变了策略身份（从"趋势确认后追入"偏向"ADX+量能启动就追入"），必须走 walk-forward 观察，不能直接替换 V35。

## 数据与执行口径

- 市场：Binance USD-M 永续，`HYPE/USDT:USDT`，`15m`。
- 数据：本地数据湖，`2025-05-30 10:30` ~ `2026-07-08 05:30 UTC`，38765 根，0 缺口 0 重复 0 空值。
- 成本：`0.00085`/fill（V35 canonical 口径，手续费+4bps 滑点合并），含 funding。
- 执行：K0 close 信号、K2 open 入场、entry ATR 取 K1、TP/SL 盘中 high/low 触发、指标退出/timeout 下一根 open 成交。

## 第二部分：微调结果与最终候选

微调网格：`long_vol_min × take_profit_atr × max_allocation × short_target_atr_pct × ema_slow × 多头 ema_spread 开关`（66 组），精简基线只移除空头 1h EMA 确认（验证与 base 完全一致后作为起点）。

最终两个候选（标准分片验证）：

### 候选 A：`v35_tuned_mild`（全面严格改进版）

改动最小：`long_vol_min 0.25 -> 0.35`、`short_target_atr_pct 0.018 -> 0.022`、移除冗余空头 1h EMA 确认；实盘规格继续保留 `max_hold_bars=384` timeout 兜底。其余参数全部不动。

| 指标 | V35 base | v35_tuned_mild |
| --- | ---: | ---: |
| full 收益 | +8360.80% | **+9969.45%** |
| full maxDD | -23.46% | -23.46% |
| Sharpe | 4.75 | **4.81** |
| full 胜率 | 78.70% | **79.44%** |
| 90d 收益 | +215.41% | **+217.53%** |
| 90d maxDD | -21.90% | -21.90% |
| 90d 胜率 | 74.29% | **77.14%** |
| 1y 收益 | +9516.21% | **+11342.95%** |
| 6m 收益 | +1766.64% | **+1802.57%** |

每个窗口都不差于 base，收益/胜率/Sharpe 全部提升，回撤持平。这是消融驱动的干净改进，不依赖最近行情假设。

### 候选 B：`v35_tuned_recent3m`（最近 90 天优化版）

在候选 A 基础上另加：移除多头 `ema_spread>0` 过滤、`max_allocation 3.0 -> 2.5`、`ema_slow 384 -> 512`。

| 指标 | V35 base | v35_tuned_recent3m |
| --- | ---: | ---: |
| 90d 收益 | +215.41% | **+254.77%** |

用户要求的三项（最近 3 个月收益更高、胜率更高、回撤更小）全部达成，但代价是 6m/1y/full 变差、full maxDD 加深 2.22pp。它是"最近行情适配版"，不是全局更优版。

## 判断与建议

1. **候选 A（`v35_tuned_mild`，已登记为 V39）值得优先推进**：它是消融驱动的严格改进，所有窗口不劣于 V35，且只动了两个数值参数加移除一个实盘可删的冗余过滤。下一步应先做 Hyperliquid/OKX 跨所同窗迁移检查和 walk-forward，再讨论 live/paper-live。
2. **候选 B（`v35_tuned_recent3m`）作为 regime 适配观察**：最近 90 天三项全优，但它明确牺牲历史全窗口表现，且移除多头 EMA spread 过滤改变了策略身份。如果最近的"弱趋势、低波动"行情持续，它会继续占优；如果回到 2025 下半年的强趋势 regime，V35/候选 A 更强。建议只做影子观察，不替换 V35。
3. **参数移除结论**：`max_hold_bars` timeout 与空头 1h EMA 确认在回测中单独移除结果均逐字节一致；但按实盘安全口径，timeout 保留为异常兜底，只有空头 1h EMA 确认进入候选 A 的删除项。
4. 两个候选均为 diagnostic，未 promotion、未 live-ready；上线前需按 live-executable 口径完成订单时序、止损挂单、重启恢复审计。
