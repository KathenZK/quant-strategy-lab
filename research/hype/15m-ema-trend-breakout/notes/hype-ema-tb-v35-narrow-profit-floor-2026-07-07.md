# HYPE-EMA-TB-V35 窄口径浮盈保护线第二轮诊断

日期：2026-07-07（同日第二轮，接续 `hype-ema-tb-v35-profit-floor-diagnostic-2026-07-07.md`）

## 结论

这个问题有可用的解，但不是原来提议的分阶段 profit floor，而是**极窄口径版本：只在 `mfe_atr >= 4.75~4.9` 时启动，锁定 `4.25~4.4 ATR`**。

- `floor_49_lock44`（`mfe>=4.9` 启动、锁 `4.4 ATR`）：full `+7972.54%`（保留 base 的 95%），maxDD `-23.46%` 与 base 完全相同，Sharpe `4.72` vs `4.75`，样本内仅 `6` 次 floor 退出。
- `floor_475_lock425`（`mfe>=4.75` 启动、锁 `4.25 ATR`）：full `+7053.02%`（保留 84%），maxDD 同 base，Sharpe `4.60`，`17` 次 floor 退出。**这是能覆盖当前实盘这单（峰值 `4.86 ATR`）的最窄档**；`4.9` 启动线覆盖不到它。
- 所有更宽的档位（启动线 `<= 4.5`）都显著破坏 V35；floor 退出后加 16 根冷却反而更差；直接把 TP 收紧到 `4.75` 也劣于同位置的 floor。

## 关键结构性事实

对 base 108 笔逐笔分解（Binance API 窗口，`2025-05-30 10:30` ~ `2026-07-07 07:45 UTC`）：

| MFE 门槛 | 达到的交易数 | 其中未 TP | 未 TP 的累计单笔收益 |
| --- | ---: | ---: | ---: |
| `>= 3.0` | 84 | 8（全部止损） | `-91.3%` |
| `>= 3.5` | 79 | 5 | `-55.3%` |
| `>= 4.0` | 64 | 2 | `-27.0%` |
| `>= 4.5` | 41 | 0 | `0.0%` |

两点推论：

1. `mfe >= 4.5` 的单在样本内 41/41 全部打到 `5ATR` 止盈。所以窄口径保护线在历史回测里**只能体现成本（把 TP 单提前截断一点），无法体现收益**；它的价值是对样本外尾部事件（如当前这单 `4.86 ATR` 后回吐）的保险。样本内成本就是保险费。
2. `3.0~4.0` 区间存在真实回吐（8 笔高浮盈单最终吃满 `-7ATR` 止损，累计约 `-91%` 单笔收益），但用 floor 保护这个区间会同时截断大量后来打到 TP 的单——试过的所有 `3.0/3.5/4.0` 档全窗口收益都掉到 base 的 40%~50%，得不偿失。

## 窄口径 floor 的成本刻画

`floor_475_lock425` 的 17 次 floor 退出中，同 entry 的 base 结局有 15 次是 take_profit：即该保护线主要把本来能吃满 TP 的单提前一点截断，floor 单均收益 `+6.75%` vs base 对应单均 `+8.47%`，每次约让出 `1.7` 个百分点。`floor_49_lock44` 仅 6 次触发（base 对应 5 次 TP），floor 单均 `+7.21%` vs `+8.60%`。

7 月实例（回放）：`2026-07-03 15:15` 入场的多单在 base 里 `07-06 01:00` 打到 TP `+8.60%`；在 `floor_475_lock425` 里 `07-04 03:45` 被 floor 截断在 `+7.92%`。注意实盘这单（入场 `70.5295`）因成交价略高于回放（`70.44`），TP 挂得更高而未触发——这正是"差一口气"的尾部形态，floor 的保险价值就在这里。

## 判断与状态

- **可推进方向**：`floor_475_lock425` 作为观察候选（能覆盖 `4.86 ATR` 场景，代价约 16% full 收益）；`floor_49_lock44` 作为更便宜的备选（代价约 5%，但覆盖线更高）。
- **明确否决**：启动线 `<= 4.5` 的所有档位、floor 退出后冷却、直接收紧 TP。
- **诚实声明**：`4.75/4.25` 这组阈值是在同一份样本上挑的，且它防护的事件（高浮盈后回吐到止损）在 `mfe>=4.5` 区间样本内发生 0 次——保险收益完全来自样本外假设。本轮全部为 diagnostic，不构成 promotion；若要上线需先按 live-executable 口径审计（floor 在实盘等价于收盘后上移 STOP_MARKET 触发价，与现有 runner 的挂单机制兼容，但需要新增"收盘后改单"路径），并建议先影子观察。
