# HYPE 日线 MA7 多空分离趋势搜索与验证

## 结论

基于图中“趋势段应持有、MA7 附近噪声不应反复翻仓”的结构，固定 `SMA7`，分别搜索多头和空头的 reclaim、斜率确认、迟滞退出、保护止损和冷却规则。搜索确实找到一个成本后历史盈利的多空组合：

- 全期 `+293.20%`，保守 MDD `-26.44%`，Sharpe `2.35`，金额 PF `12.41`；
- 同期计双边成本和事件级 funding 的 `1x` buy-and-hold 为 `+50.82%`，历史超额 `+242.38` 个百分点；
- `8 bps/fill` 下为 `+289.25%`；
- 所有信号额外延迟一天仍为 `+140.58%`；
- 多头单独为 `+151.91%`，空头单独为 `+52.31%`。

但这不是已经验证可上线的策略。最终组合是在最后 `90d` 被揭示后从候选前沿二次选择，只有 `13` 笔完整交易；`12:00 UTC` 相位收益为 `+28.97%`，虽仍盈利，但仅为原生相位的 `10.1%`，显著低于默认 `40%` 相位门槛。结论只能是：**找到一个历史盈利、值得做 prospective observation 的候选；保持 `explore / not promoted / not live-ready`，不登记版本。**

## 图形假设与机制调整

初始规则逐次根据 MA7 穿越进出，造成高换手并把趋势中的正常回踩当作反转。新搜索保留 `SMA7` 核心，但只在以下结构发生时入场：

1. 价格从 MA7 附近重新回到趋势方向；
2. MA7 自身斜率与方向一致；
3. 退出使用 `0.75 ATR` 迟滞带和 `1.5 ATR` trailing stop，而不是首次穿越即离场；
4. 多空参数独立：空头使用 2 日负斜率确认、1 日斜率反转退出、`1.5 ATR` hard stop 和更长的 `4 ATR` trailing stop。

精确规则见[候选观察规格](../specs/hype-1d-ma7-abt-separated-trend-observation-2026-08-04.md)。

## 数据与执行口径

- 市场：Binance USD-M Futures `HYPEUSDT` perpetual，UTC `1d`。
- 数据：标准数据湖 `1h` 聚合完整日 K；`2025-05-31` 至 `2026-07-30 UTC`，`425d`。
- 数据质量：raw/normalized 对齐、时间连续、无重复键、关键字段与 OHLC 校验通过。
- 指标：固定 `SMA7`；`ATR7` 为日 true range 的 7 日简单移动平均。
- 成本：手续费 `0.001/fill`、不利滑点 `4 bps/fill`；funding 按实际 Binance 事件 timestamp 与 rate、仅在真实持仓区间结算，名义使用事件所在 `1h` K open 近似。
- 仓位：单仓、非加仓、成交后约 `1x`，成交间数量不变。
- 时序：收盘信号最早在下一日 open 成交；trailing stop 在收盘后更新并从下一日生效；任一 `1h` open 跳空穿越保护价时按该小时 open 成交。
- 止损路径：用真实 `1h` high/low 定位首个命中小时；MDD 只纳入命中前已完成小时和止损成交，不使用止损后的当日极值。
- 证据角色：所有历史均已被研究者查看，不是 clean prospective OOS。

## Monte Carlo 与参数邻域

按 13 笔历史 campaign 有放回抽样 `5,000` 次：

- 终值 5% / 中位 / 95%：`2.007x / 3.853x / 8.080x`；
- 盈利概率：`100.00%`；
- 仅在已平仓交易边界计算的回撤中位数：`-6.87%`。

该结果只表示已观察交易分布在 i.i.d. 重采样下为正，不捕捉持仓内 MAE、日内路径、regime 顺序或参数选择偏差；其回撤不是完整路径 MDD，也不能克服仅 13 笔的样本不足。

对多空入场带、斜率、退出带、hard stop 和最长持仓做单参数邻域扰动：

- 所有邻域变体全期仍为正，约 `+89.97%` 至 `+322.22%`；
- 所有邻域变体最后 `90d` 仍为正，约 `+8.56%` 至 `+62.92%`；
- 最大降幅来自把空头入场带从 `0.10 ATR` 降到 `0`；给多头增加 `1 ATR` hard stop 也把全期收益降至 `+108.26%`。两者仍盈利，但说明入场迟滞与长仓首日保护都不是可静默改动的无成本安全件。

证据见[参数邻域 CSV](../artifacts/hype_1d_ma7_separated_primary_neighborhood_2026-08-04.csv)与[机器摘要](../artifacts/hype_1d_ma7_separated_summary_2026-08-04.json)。

## 门禁判定

- Gate 0（超额收益）：历史观察通过；全期高于 buy-and-hold `242.38` 个百分点，但存在 post-reveal 选择偏差。
- Gate 1（消融）：诊断支持；long-only 与 short-only 均为正，但独立交易数不足。
- Gate 2（OOS / CPCV）：未通过；最终候选经过最后 `90d` 二次筛选，无 clean OOS，且全期只有 13 笔。
- Gate 3（Monte Carlo）：诊断支持；交易 bootstrap 与局部参数邻域为正，但同样基于已揭示、已选择历史。
- Gate 4（压力与执行）：部分支持但未通过 live-readiness；`8 bps` 与额外延迟仍盈利，尚无拒单、断流、重启和跳空极端逐段审计，多头首个持仓日无 hard stop。
- Gate 5（相位）：失败；`12h/0h` 收益比 `10.1% < 40%`，且相位/起跑点覆盖不足。
