# HYPE 1D MA7 V6：RSI6 记忆 Cross 入场消融

## 裁决

本轮结论为 **FAIL / 不登记 V7 / 不改变 V6**。

用户提出的对称主规则确实提高了全历史收益，但没有同时降低回撤：`A1_PRIOR5_BOTH`为累计`+662.27%`、折算年化`+456.29%`、真实小时顺序MDD`-21.97%`，对照exact V6为`+617.11% / +428.31% / -18.39%`。收益增加`45.16pp`，但最大回撤扩大`3.57pp`。

方向拆分后，证据很清楚：

- **多头记忆规则有价值，但只有1个历史事件。** 它把2026-01-27的V6多头提前到2026-01-25，保持同一退出，将该笔净收益从`+20.47%`提高到`+29.39%`；全窗提高到`+670.19%`，MDD与V6相同。但这不是新增第二个独立盈利episode，不能据此登记版本。
- **空头记忆规则整体有害。** 两次新空分别为`+3.51%`与`-4.38%`，使全窗降至`+609.74%`且MDD扩大至`-21.97%`。
- **包含cross当天的5日敏感性看起来最好，但仍不是过门候选。** `A4_INCLUSIVE5_BOTH`为`+697.19% / -18.39%`，只保留盈利空头和提前多头，恰好排除了亏损空头；它属于预先冻结的语义敏感性，不是主规则，而且MDD只是相同、并未下降。
- **RSI记忆不能取代V6原生入口。** 关闭全部原生入口后只剩`+74.97% / -23.76%`，说明它最多是稀疏补充条件，不是完整趋势识别器。

## 冻结规则

主规则`A1_PRIOR5_BOTH`在exact V6上以OR方式新增两类自然入场：

1. 当日收盘由MA7下方穿到上方；此前5个完整UTC日中至少3日Wilder RSI6严格小于30；下一UTC日open开多。
2. 当日收盘由MA7上方穿到下方；此前5个完整UTC日中至少3日Wilder RSI6严格大于70；下一UTC日open开空。

`PRIOR5`不含cross当日。新增入口绕过V6原生入场的slope及空头`0.10ATR`距离门，但仍要求当时flat、方向cooldown已解锁；入场后完整继承V6的`0.75ATR`迟滞趋势容错、保护、固定OAPP、short RSI6止盈和`PEHC_294`。没有搜索RSI阈值、窗口或计数。

## 为什么对称规则没有成功

RSI极值记忆回答的是“cross之前是否经历过极端阶段”，并不直接证明cross之后会持续形成新趋势。超卖后的上穿在样本中有一次成功的均值回归转趋势；超买后的下穿则一好一坏，错误空头不仅自身亏损，还改变单仓资金曲线并放大组合回撤。因此，对称地把`<30`映射到多头、`>70`映射到空头，并没有得到对称的预测质量。

更重要的是，`A2`的提升全部集中在同一个已暴露episode，`A4`的优势又来自“窗口是否包含cross日”恰好排除一笔亏损空头。继续在这432日上搜索`2/5、4/5、25/75、窗口4/6日`会直接变成针对三次事件调参，不能产生可信的新版本。

## 最终决定

1. 不把`A1_PRIOR5_BOTH`加入V6；不登记V7，不研究杠杆，不推进runner。
2. 明确否决对称的`PRIOR5`空头规则；它在本窗内降低收益并扩大回撤。
3. `A2_PRIOR5_LONG_ONLY`只保留为一个值得前瞻观察的机制假设，不作为候选：至少需要新增、未暴露的多个超卖记忆上穿episode，才能判断是否稳定有效。
4. `A4_INCLUSIVE5_BOTH`只记录为语义敏感性，不能在看过结果后替换主规则。
