# HYPE-30M-Keltner-Trend-Breakout-V3 全参数消融与多周期稳健性

日期：2026-07-17

版本：`HYPE-30M-Keltner-Trend-Breakout-V3`

状态：`registered / not promoted / not live-ready`

目的：检查 V3 各接线组件、全部冻结参数邻域、交易方向、历史滚动窗口、交易 bootstrap、K 线相位及不同信号周期的稳健性。本报告只做诊断，不修改 V3 参数或登记新版本。

## 结论

V3 在**固定 30m 信号 / 1h 趋势定义内**具有真实但不均匀的 alpha：全部 73 个单参数邻域变体仍为正收益；12 个非重叠 30 天历史窗口中 11 个为正；5,000 次交易 bootstrap 的收益 5% 分位仍为 `+1477%`。

但整体稳健性结论仍是**未通过**：

1. 策略几乎不能迁移到 15m、1h、2h；15m 变体严重亏损，1h 仅有极少或零交易，2h 无交易。
2. 30m 原生边界依赖仍严重。非原生相位收益中位数仅为原生的 `13.97%`，跨相位收益 CV `1.167`，MDD 比 `2.10x`，三项均不满足现行门禁 5。
3. `Keltner multiplier=2.0`、`Keltner EMA=10`、`TP=10%`、`hold=30` 都位于明显的局部绩效峰值；邻域虽未转负，但收益衰减很大。
4. close-location 过滤不是强风险组件：移除后收益反而从 `+6328.98%` 升至 `+6949.07%`，MDD不变，仅胜率低 `0.89pp`。它更像胜率偏好，而不是已证明的稳健性来源。
5. 空头腿只有 `+75.37% / MDD -27.15% / 31 笔`，显著弱于多头腿的 `+3565.97% / MDD -17.84% / 47 笔`。

因此 V3 保持 `registered / not promoted / not live-ready`，不得据此进入 `live spec` 或 runner。

- UTC 区间：`2025-05-30 00:00` 至 `2026-07-13 06:06`。
- 数据质量：`588,697` 行；缺失分钟、重复时间戳、非法 OHLC、关键空值均为 `0`。
- 基线周期：`30m` 信号 + `1h` trend regime。
- 入场：信号收盘后下一根信号周期 open。
- 成本：手续费 `0.001/fill` + 不利滑点 `0.0004/fill` + Binance 历史 funding。
- 同 bar TP/SL：SL 优先；stop gap 按 open 加不利滑点。
- 最近切片只作审计，不参与本轮参数选择。

基线复现：`+6328.98% / MDD -22.68% / Sharpe 5.05 / 胜率 67.95% / 78 笔`，与 V3 冻结 artifact 对齐。

## 不同时间周期

测试两种口径：

1. `native_bar_counts`：15m/30m/1h/2h 均保留相同数字参数，趋势周期固定为信号周期的 2 倍。
2. `clock_normalized`：按时间比例缩放 EMA/ATR/hold 窗口，并按平方根时间缩放 ATR target 与 ATR cap，使观察时长和波动预算尽量接近 30m 基线。

## 决策

- V3 参数不变，不创建新版本。
- V3 保持 `registered / not promoted / not live-ready`。
- close-location 过滤记为待重审组件；在独立未来样本不足前不因全样本收益更高而删除。
- 空头腿记为弱腿；是否 long-only 必须另做预先冻结的未来验证，不能在本报告后验删除。
- 进入任何 promotion review 前，必须先解决或解释 30m 原生边界效应，并补齐真实未来 OOS 与 live-executable / Gate 4 证据。
