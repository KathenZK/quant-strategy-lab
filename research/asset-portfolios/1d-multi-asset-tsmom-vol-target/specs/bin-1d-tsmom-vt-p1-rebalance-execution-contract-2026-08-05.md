> 研究问题只有一个：**在完全不动 P0 信号层与仓位层的前提下，预注册的再平衡纪律能否把成本漏损压到因子毛利可以覆盖的水平？**

## 1. 继承项（自 P0 契约冻结，本轮禁止改动）

以下全部沿用 [P0 演示契约](bin-1d-tsmom-vt-demo-contract-2026-07-27.md)，任何改动即为违约：

- 信号：过去 `30/91/182/365` 自然日收盘收益率符号均值，最少 2 个可用回看，全部用 T−1 收盘及更早数据；`s_i ∈ [−1, +1]`，多空对称。
- 仓位目标：单资产 `w_i = s_i / σ_i`（日收益 EWMA 波动，半衰期 20 日，年化 ×√365，T−1 截止），宇宙内归一化 `Σ|w_i| = 1`，单币 `|w_i| ≤ 0.10`（截断不回补）；组合层按未缩放组合收益 EWMA 波动（半衰期 20 日）缩放到年化 20% 目标，总杠杆上限 2.0×。
- 宇宙：point-in-time 月度刷新，非排除标的、历史 ≥ 91 个交易日、ADV30 ≥ 1000 万 USDT，取前 30 名当月固定；出宇宙次日平仓。仅加密永续（稳定币/法币基础与 `underlyingType ≠ COIN` 标的剔除）。
- 成本：换手名义 × (手续费 `0.001` + 滑点 `4 bps`)/边（仓库 Binance 默认口径）；资金费逐日 as-of 计入，纯成本处理，缺失记 0 并报告覆盖率。
- 执行时序：T−1 收盘后计算目标，T 日按收盘-收盘收益持有；缺日收益记 0 并强制次日清仓该币。

明确不在本轮范围（各需未来单独契约）：EWMAC 或其他信号替换、回看集调整、carry/资金费信号化、maker 成交假设作为主口径、TradFi 永续宇宙扩展、多资产类别 ETF/期货数据接入。

## 2. P1 变化项：再平衡纪律（预注册变体集，禁止搜索）

唯一改动点是"目标权重 → 实际交易"的映射。每日照常计算目标权重 `w*_i`，但只在满足触发条件时下单。固定 6 个变体，全部跑、全部报告：

| 变体 | 再平衡规则 |
|---|---|
| E0（P0 复刻对照） | 每日全量再平衡到目标（复刻 P0，用于缓存重建校验与归因基线） |
| **E1（主变体）** | 每日检查：仅当 `|w*_i − w_held_i| ≥ 0.005`（权益的 0.5%）时将该资产调到目标，否则持仓不动 |
| E2 | 同 E1，阈值 `0.0025` |
| E3 | 同 E1，阈值 `0.010` |
| E4 | 每周一（UTC）全量再平衡到目标，其余日不动 |
| E5 | 每周一检查 + E1 阈值 `0.005` |

- 强制交易覆盖缓冲带（所有变体一致）：出宇宙次日平仓；缺日收益强制次日清仓；信号符号翻转视为普通目标变化，仍走触发条件。
- **主变体 E1 在冻结时指定**。kill gate 只对 E1 判定；若 E1 失败而其他变体通过，该变体**不得**从本契约晋升或登记，只能作为下一份新契约的先验假设。
- E2/E3 用于单调性检查（阈值越宽换手应越低、跟踪差应越大），不用于择优。

## 5. 预注册 kill gate（只对 E1、主评估窗、净口径判定）

1. 全期净收益为正，且 5 个自然年中 ≥ 3 年为正；
2. 单一年份利润占比 < 70%（全期为正时计算）；
3. 实现年化波动落于 `[10%, 30%]`；
4. 最大回撤 < 40%；
5. 年单边换手 ≤ 12×，且交易成本拖累 ≤ 2%/年（P0 为 34× 与 ~4.8%/年）；
6. E1 毛价格 PnL ≥ E0 毛价格 PnL 的 70%（缓冲带不得明显毁掉因子捕获）。

判定纪律：

- 任一条不过 → E1 执行路线判死，家族保持 `explore / not promoted / not live-ready`；**禁止**在同一评估窗上调阈值重跑再引用（新阈值 = 新契约）。
- 全部通过 → 可提议登记 V1（登记仍需用户确认，且按登记≠晋升处理）；后续晋升另走验证门禁与前瞻观察。
