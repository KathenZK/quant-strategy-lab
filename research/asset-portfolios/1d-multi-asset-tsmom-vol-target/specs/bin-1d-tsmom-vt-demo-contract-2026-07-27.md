# BIN-1D-TSMOM-VT 演示基线契约（P0）

> 状态：`registered`（研究契约，非晋升）。在查看任何回测结果**之前**冻结；所有参数一次预注册，禁止看结果后回调重跑再引用。本线是教学演示 + 可行性基线，直接实现学术上证据最厚的因子组合：多资产时序动量（Moskowitz-Ooi-Pedersen 2012 TSMOM）+ 波动率目标仓位。

## 1. 数据与范围

- 市场：Binance USD-M USDT 永续，`1d`（由已审计 `1h` Vision 归档 UTC 日边界重采样，复用 [`emax_1d_derived` 缓存](../../1d-ema-cross-lightgbm-event-selector/diagnostics/bin-1d-emax-lgbm-p1-baseline-2026-07-24.md)记录的衍生口径）。
- 宇宙：仅加密永续。稳定币/法币基础与非加密标的（美股/商品/指数等 146 个）按 15m 家族 inventory 的 `underlying_type` 剔除；美股等 TradFi 永续历史最长 5 个月（2026-02 起）且全部落于 `2026H1`，本轮不可用，列为声明的未来扩展。
- 评估窗口：2021-01-01 至 2025-12-31（UTC）；2020-07 起仅用于波动率估计暖机。`2026-01`–`2026-06` 为本研究计划的污染保留窗，不参与评估。
- 资金费：Binance funding 归档（as-of），按日聚合计入持仓损益；缺失覆盖率必须报告，缺失记 0 并声明。

## 2. 宇宙构建（point-in-time，月度刷新）

每月首日，用截至上月末的数据确定当月宇宙：

- 资格：非排除标的；历史 ≥ 91 个交易日；30 日平均日成交额（quote volume）≥ 1000 万 USDT。
- 取资格币中 ADV30 前 30 名，当月固定；出宇宙的币次日平仓（付成本）。

## 3. 信号（经典 TSMOM 集成，无任何拟合）

- 回看集：过去 `30 / 91 / 182 / 365` 个自然日的收盘价收益率符号（+1 / −1），全部用 T−1 收盘及更早数据。
- 信号 `s_i` = 可用回看的符号均值（上市不足 365 天的币用其已可用的回看，最少 2 个，即 ≥ 91 天历史）；`s_i ∈ [−1, +1]`，多空对称。

## 4. 仓位（两层波动率目标）

- 单资产层：原始权重 `w_i = s_i / σ_i`，`σ_i` 为日收益 EWMA 波动（半衰期 20 日，年化 ×√365），用 T−1 及更早数据；对在宇宙内的币归一化到 `Σ|w_i| = 1`，单币权重上限 `|w_i| ≤ 0.10`（截断不回补）。
- 组合层：用组合自身未缩放日收益的 EWMA 波动（半衰期 20 日，T−1 截止）做缩放，`scale = min(20% / σ_p, 2.0)`；目标年化波动 20%，总名义杠杆上限 2.0×。
- 执行时序：T−1 收盘后计算信号与权重，T 日按收盘-收盘收益持有（1d 粒度下 T 日 00:00 开盘 ≈ T−1 收盘，为声明的近似）；缺日收益记 0 并强制次日清仓该币。

## 5. 成本

- 交易成本：换手名义 × (手续费 0.001 + 滑点 4 bps)/边，按每日 `Σ|Δw|` 计。
- 资金费：`− w_i × 当日资金费率合计`（多头付正费率），逐日计入。
- 无借贷成本假设（USDT 本位，全保证金内运作）。

## 6. 报告义务

- 全期与逐年净收益、最大回撤、Sharpe、实现年化波动 vs 20% 目标、平均/峰值总杠杆。
- 归因：价格 PnL / 交易成本 / 资金费三项拆分；多头腿 vs 空头腿逐年；年均换手。
- 对照：同窗口 BTC 买入持有（同成本口径免换手）。
- 近期分片（锚定 2025-12-31，仅审计）：最近 1d/7d/1m/3m/6m/1y。
- 产物：`tsmom_vt_demo_report.json`、权益曲线 parquet、曲线图 PNG，入 `artifacts/`。

## 7. 预注册评价（演示级，非晋升门槛）

1. 全期净收益为正，且 5 个自然年中 ≥ 3 年为正；
2. 单一年份利润占比 < 70%（全期为正时计算）；
3. 实现年化波动落于 `[10%, 30%]`（波动率目标机制有效）；
4. 最大回撤 < 40%。

任何一条不满足不判"家族死亡"（这是首个演示基线，不是 kill gate），但必须在诊断中逐条如实判定并解释。后续若立正式版本（Vx），需另立含 kill gate 的契约。
