# BIN-15M-TSM P2 组合基线（2026-07-28）

> 状态：`diagnostic / dev-window in-sample / not promoted / not live-ready`
>
> 裁决：修订后 canonical（`EMA336/1536`, θ 1.0/0.25, N4）组合层 **4 项 kill gate 全部通过**（净收益 > 0、1.5x 成本仍 > 0、MaxDD ≤ 40%、成本拖累 ≤ 30%/年）。家族达到锁定 OOS 揭示资格；揭示为一次性动作，待用户裁决。

## 1. 口径与实现细则

- 市场/成本：Binance USD-M USDT 永续 `15m`；每次成交 `0.001` 手续费 + `4 bps` 滑点（按换手名义计）；funding 在结算时刻按当时持仓带方向计入（多头付正 funding）；压力 `1.5x` 交易成本。
- 数据/窗口：同 [P1](bin-15m-tsm-p1-segment-baseline-2026-07-28.md)；开发窗 `2020-01-01`–`2025-12-31 UTC`；锁定 OOS 未触碰。曾入交易池币 577 个。
- 状态层：P1 状态机原样复用（含出池强平），状态切换 15m 粒度即时生效。
- 仓位层（复用 [BIN-1D-TSMOM-VT 契约](../../1d-multi-asset-tsmom-vol-target/specs/bin-1d-tsmom-vt-demo-contract-2026-07-27.md)两层波动率目标），实现细则如下声明：
  - 单币 `w_i = state_i / σ_i`，`σ_i` 为日收益 EWMA 波动（半衰期 20 日、年化、T−1 移位、最少 10 个观测）；在当根有非零状态的币上归一化 `Σ|w|=1`；单币 cap `0.10`（截断、不再分配）。
  - 组合层 scale = `min(20% / σ_p, 2.0)`，`σ_p` 为未缩放组合日收益的 EWMA 波动（半衰期 20 日、T−1 移位；不足 10 个观测时 scale=1）。
  - `σ_i` 与 scale 每日 `00:00 UTC` 冻结；15m 权重仅因状态切换与归一化分母变动。
  - 记账近似（声明）：按 15m close-to-close 收益、权重滞后一根生效，近似 `t+1` open 成交；成本按每根 `Σ|Δw| × 0.0014` 计。

## 3. 诚实声明与风险

1. **2025 全年为负**（−9.0%，压力下 −11.8%），近 1y 分片为负；2022 在 1.5x 压力下仅 +0.4%。盈利集中在 2020/2021/2023 趋势年，震荡年基本白干或失血——TSMOM 形态，入场前必须接受这类年份。
2. 收益高度依赖多头侧（毛收益多:空 ≈ 4.5:1）；空头侧主要在熊市年提供对冲。
3. 记账为 close-to-close 近似而非逐笔 open 成交撮合；15m 相邻 bar 边界误差极小，但 promotion 前需按 live runner 时序做执行审计（本报告不构成 live-ready 证据）。
4. 锁定 OOS `2026H1` 为**二次 reused holdout**（已被 CSLGBM 与 15m emax 揭示过），证据强度预先声明降级；即使通过，promotion 讨论前仍须 ≥3 个月前瞻观察。
