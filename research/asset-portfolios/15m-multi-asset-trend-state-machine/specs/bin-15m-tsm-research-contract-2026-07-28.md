# BIN-15M-TSM 冻结研究契约（2026-07-28）

本契约在任何回测运行之前冻结。修改任何"冻结"条目必须在 [decision-log.md](../decision-log.md) 记录原因，且不得发生在锁定 OOS 揭示之后。

> **修订记录（2026-07-28，OOS 揭示前，用户批准）**：P1 裁决显示原 canonical 方向核 `EMA96/384` 尺度身份 gate 失败（84.5 次/池年 > 60），预注册敏感性集中备选核 `EMA336/1536` 27 组全部通过双 gate。经用户批准，方向核修订为 `EMA336/1536`（≡ 4h EMA21/96），`θ_in/θ_out/N = 1.0/0.25/4` 不变，其余条款不动。原核数字保留在 [P1 诊断](../diagnostics/bin-15m-tsm-p1-segment-baseline-2026-07-28.md)。锁定 OOS 在本修订时点未被读取。

## 1. 研究问题与机制身份（冻结）

- 问题：每根已闭合 `15m` K 收盘重估每个币的趋势状态（`LONG / FLAT / SHORT`），状态切换时换仓——一个"**15m 采样、4h/1d 有效尺度**"的多资产趋势状态机在扣全成本含 funding 后是否有净期望。
- 形态：持续持仓状态机 + 迟滞（Schmitt trigger）退出。无 ML、无固定 bracket、无每段硬止损（身份声明；P1 必须报告最差段分布，后续任何保护线都构成新版本与新审计）。
- 与已归档 [`BIN-15M-EMAX-LGBM`](../../15m-ema-cross-lightgbm-event-selector/README.md) 的机制差异声明（治理要求）：
  1. 该线是事件 + 固定 bracket + LightGBM 打分；本线是状态机持仓 + 迟滞退出，无模型。
  2. 该线趋势定义在 15m 交叉尺度（EMA21/96 on 15m），其 [P1 基线](../../15m-ema-cross-lightgbm-event-selector/diagnostics/bin-15m-emax-lgbm-p1-baseline-2026-07-24.md)测得毛期望≈0；本线状态定义在 4h 等效尺度（修订后 `EMA336/1536` on 15m ≡ `EMA21/96` on 4h），依据是 emax 周期梯度（15m→1h→4h→1d）毛期望单调走强、净期望在 1h–4h 间穿零的测量结论。
  3. 改变的核心假设：不再假设"15m 尺度的趋势起点可识别"，改为假设"4h/1d 尺度的趋势状态存在可收割残差；15m 采样只用于更早响应状态切换"。

## 2. 状态机定义（冻结 canonical）

特征全部用已闭合 `15m` K：

- `EMA336`、`EMA1536`（2026-07-28 修订，原 `EMA96/384`）：`close.ewm(span=n, adjust=False, min_periods=n).mean()`。
- `ATR672`：true range 的 672 根简单滚动均值（≈7 天，`min_periods=672`）。
- `spread_atr = (EMA336 − EMA1536) / ATR672`。

状态规则（迟滞 + 确认）：

- 进入 `LONG`：连续 `4` 根已闭合 K 满足 `spread_atr ≥ +1.0`。
- `LONG` 维持，直到连续 `4` 根满足 `spread_atr ≤ +0.25` → 退回 `FLAT`。
- `SHORT` 对称：连续 `4` 根 `spread_atr ≤ −1.0` 进入；连续 `4` 根 `spread_atr ≥ −0.25` 退出。
- 不允许当根直接翻向：先按退出规则回 `FLAT`，反向确认计数从 `FLAT` 后重新累计。
- 暖机：任一特征未达 `min_periods` 时强制 `FLAT`。

执行（冻结）：

- 状态在 bar `t` 收盘确认，仓位变更在 bar `t+1` open 成交。
- 币退市或跌出交易池：持仓段在下一根 open 强平，退出原因记 `pool_exit`。

## 3. 成本模型（冻结，同 emax 家族）

- 每次成交：手续费 `0.001` × 名义 + 不利滑点 `4 bps`；来回基础成本 `0.28%` 名义。
- funding：按实际持仓区间与方向 as-of 计入；缺失 funding 不得静默填 0。
- ATR 单位口径的期望必须用**该币该时刻的 ATR/价格**折算成本；禁止全局常数成本。
- 压力测试：基础成本 `1.5x`。

## 4. 数据与窗口（冻结）

- 数据：完整复用 [`BIN-15M-EMAX-LGBM` P0 冻结数据湖](../../15m-ema-cross-lightgbm-event-selector/diagnostics/bin-15m-emax-lgbm-p0-data-freeze-2026-07-24.md)（Binance Vision USD-M `15m`，790 个 USDT 永续，`2020-01`–`2026-06`，已审计零缺口零重复）与既有 funding 归档；本线不新增同步。
- 开发窗：`2020-01-01` ≤ ts < `2026-01-01 UTC`。
- 锁定 OOS：`2026-01-01`–`2026-06-30 UTC`。诚实声明：该窗口已被 `BIN-1H-CSLGBM` 与 `BIN-15M-EMAX-LGBM` 两次揭示，属 **二次 reused holdout**，证据强度降级；即使通过，promotion 讨论前仍须 ≥3 个月前瞻观察。开发期脚本不得读取该窗口策略表现。
- 近期分片（`1d/7d/1m/3m/6m/1y`）锚定开发窗末（`2025-12-31`），仅审计，不用于选择。

## 5. 币池（冻结，复用 emax 规则）

- 训练池（point-in-time）：上市满 `30` 天；ADV30 ≥ `1000` 万 USDT；近 30 天 K 线覆盖率 ≥ `95%`；剔除稳定币对与非 COIN underlying；退市币保留至退市前 `7` 天。
- 交易池：训练池内 ADV30 滚动前 `120`。**P1 期望 gate 与 P2/OOS 成绩只在交易池上计算。**

## 6. P1 段级裸基线（先测原料，后谈聪明）

- 每币每个状态段（`FLAT→LONG→FLAT` 等）= 一笔：`t+1` open 入场、状态退出后 `t+1` open 出场（或 `pool_exit` 强平）。名义 1 单位测量、不复利；逐段净收益以 ATR 单位与 `%` 双口径记录，含 funding。
- 报告义务：全体池/交易池、多空分侧、逐年、段持续时间分布、每币年均往返、成本占净结果比例、最差段分布、近期分片。
- **尺度身份 gate（冻结）**：交易池段持续时间中位数 ≥ `96` 根 15m（24h），且交易池每币年均完整往返 ≤ `60`。不满足 = 状态定义未达到 4h/1d 有效尺度，机制身份不成立 → 停（重定义视同新契约）。
- **期望 gate（冻结）**：交易池逐段净期望 ≤ 0 且多空两侧均 ≤ 0 → 停，家族记负结果归档。
- 预注册单侧分支：若仅单侧净期望 ≥ `+0.10 ATR`/段且逐年多数为正，允许以该单侧版本进入 P2（依据 emax 梯度"空头侧跨周期更强"的先验；此分支为预注册决策，不算事后调参，启用时记 decision log）。

## 7. 预注册敏感性集（P1 一并全量报告）

- `θ_in ∈ {0.75, 1.0, 1.5}`、`θ_out ∈ {0.0, 0.25, 0.5}`、确认根数 `N ∈ {1, 4, 8}`、方向核 `{EMA96/384, EMA336/1536}`。
- 全部组合逐一报告；canonical（修订后 `1.0 / 0.25 / 4 / EMA336/1536`）不因敏感集表现更换。若 canonical 位于断崖（相邻格子净期望符号翻转），必须在诊断中明示并按参数尖峰处理。核修订本身经由 P1 身份 gate 裁决 + 用户批准 + decision log 记录完成，见文首修订记录。

## 8. P2 组合基线（P1 通过后）

- 仓位复用 [`BIN-1D-TSMOM-VT` 契约](../../1d-multi-asset-tsmom-vol-target/specs/bin-1d-tsmom-vt-demo-contract-2026-07-27.md)的两层波动率目标：单币 `w_i = state_i / σ_i`（日收益 EWMA 波动，半衰期 20 日），对在池币归一化 `Σ|w|=1`、单币 cap `0.10`；组合层目标年化波动 `20%`、总杠杆上限 `2.0x`。权重每日 `00:00 UTC` 重估；状态切换在 15m 粒度即时生效。
- Kill gate（冻结）：交易池组合扣全成本含 funding 净收益 > 0；`1.5x` 成本下仍 > 0；开发窗 MaxDD ≤ `40%`；须对照同窗 BTC 买入持有。组合年换手与成本拖累必须报告；成本拖累 > 年化 `30%` 名义 → 视为状态定义过快，停。

## 9. 锁定 OOS 硬门槛（冻结初值；只允许收紧并记录）

- 交易池组合级、扣全成本含 funding：闭合段数 ≥ `200`；净收益 > 0；PF ≥ `1.2`；MaxDD ≤ `20%`；`1.5x` 成本压力下净收益仍 > 0。
- 任一失败 → `HARD-GATE-FAILED`：家族记录失败并归档，不得用已揭示窗口调参重试。
