# HYPE/BTC/ETH/SOL 趋势生态丈量报告（2026-08-03）

## 结论先行

本轮得到的不是“趋势策略做不出来”，而是更具体的四条结论：

1. **四个资产都存在可观的 `3d/7d/14d` 强趋势事件，但 HYPE 并不比其他资产更常产生波动归一化后的强趋势。** HYPE 的绝对振幅最大，却没有更高的 scaled amplitude；在 `3d` 上，它的路径效率显著低于 BTC/ETH/SOL。HYPE 更像“位移大、噪声也大”，不是天然最容易交易的趋势载体。
2. **趋势一旦事后确认已经成为强趋势，确实往往还有很长尾巴。** HYPE 强趋势在等待 `24h` 后，终点位移中位数仍剩约 `64%/86%/93%`（对应 `3d/7d/14d`），成本 hurdle 后为正的比例约 `91%/100%/100%`。但这是以未来完整路径定义强趋势的事后条件，不能直接变成入场信号。
3. **HYPE 的主要失败点是事前识别，不是趋势完全不存在。** 冻结的过去 `7d/28d` 同向 admission 在 HYPE 的 Long、Short 和三档 horizon 上全部为负；等待最初 `4h/12h/24h` 价格走出来后再顺着初始位移，也没有恢复稳定延续。HYPE 上越快、越大的初始位移甚至更像阶段性耗竭。
4. **增加资产有意义，但不是把 HYPE 同一套参数复制四遍。** BTC/ETH 的归一化趋势 habitat 不弱于 HYPE，且简单 admission 在部分历史和方向上有正值；ETH 的 `4h` 高强度初始位移出现了值得独立前瞻验证的延续现象。跨资产的价值是增加不同类型的趋势机会，并允许资产/方向分治，不是分散同一负期望规则。

当前决策：`diagnostic-only / no strategy version / not promoted / not live-ready`。本轮所有结果已经揭示，任何后续策略都必须另立合同和新的 prospective OOS。

## 1. 研究口径

- Universe：Binance USD-M perpetual `HYPE/BTC/ETH/SOL`。
- 输入：闭合 `15m` OHLCV/funding，四根完整 bar 聚合为 `1h`；只用 close 路径的幅度、速度、效率和回吐，不使用传统技术指标。
- Anchor：每日 `00:00 UTC`；future horizon 为 `72/168/336h`。
- 共同窗口：`2025-06-30 00:00 UTC` 至 `2026-06-30 00:00 UTC`，每资产约 `365/366` 个日频 anchor，合计 `4,391` 个 anchor-horizon 行。
- 风险尺度：过去 `720h` hourly log-return RMS；`1R = RMS × sqrt(24)`。
- 成本：一次进出 `28bps`，另计对应 horizon 内实际 funding。
- 强趋势预定义：`scaled_amplitude >= 1.5` 且 `daily_efficiency >= 0.35`。
- 重叠样本：HYPE 与其他资产的共同窗比较使用 `27` 个 `14d` calendar blocks、`5,000` 次 block bootstrap。

完整定义见[冻结合同](../specs/binance-1h-fatha-initial-research-contract-2026-08-03.md)。

## 3. 事后趋势 habitat：HYPE 振幅最大，但不更顺滑

共同窗口、Long/Short 合并的主结果：

| 资产 | horizon | 中位绝对位移 | 中位 scaled amplitude | 中位 daily efficiency | 强趋势率 |
|---|---:|---:|---:|---:|---:|
| BTC | 3d / 7d / 14d | 2.39% / 3.74% / 5.03% | 0.66 / 0.64 / 0.62 | 0.62 / 0.37 / 0.26 | 12.8% / 13.1% / 14.5% |
| ETH | 3d / 7d / 14d | 3.78% / 5.57% / 7.31% | 0.68 / 0.64 / 0.59 | 0.69 / 0.37 / 0.25 | 14.5% / 14.2% / 15.0% |
| HYPE | 3d / 7d / 14d | **5.26% / 7.97% / 10.72%** | 0.62 / 0.56 / 0.56 | 0.54 / 0.33 / 0.21 | 12.9% / 11.2% / **7.4%** |
| SOL | 3d / 7d / 14d | 4.17% / 5.66% / 8.65% | 0.65 / 0.60 / 0.63 | 0.64 / 0.33 / 0.23 | 13.1% / 14.8% / 10.4% |

配对 bootstrap 给出更严格的判断：

- HYPE 的绝对位移在全部 horizon 上都高于 BTC/ETH/SOL，95% CI 均在零以上。
- scaled amplitude 的 HYPE-minus-other 95% CI 全部跨零，不能说 HYPE 的风险调整趋势更强。
- `3d` daily efficiency 的 HYPE-minus-BTC/ETH/SOL 95% CI 分别约为 `[-0.087,-0.016]`、`[-0.119,-0.021]`、`[-0.095,-0.006]`，HYPE 明确更低。
- `7d/14d` 的效率和强趋势率多数 CI 跨零；其中 HYPE `14d` 强趋势点估计最低，但当前共同窗不足以把所有差异都定为显著。

所以“肉眼看 HYPE 趋势明显”主要来自百分比振幅，而不是更少反复、更高延续效率或更高强趋势发生率。

## 4. 强趋势的可追踪性：尾巴存在，难点在早期确认

只看事后强趋势路径：

| 资产 | horizon | 强趋势样本 | 24h 后中位剩余位移占比 | 24h 后超过成本比例 | `2R` 后半 MFE 保护触发率 |
|---|---:|---:|---:|---:|---:|
| BTC | 3d / 7d / 14d | 47 / 48 / 53 | 68% / 86% / 98% | 94% / 100% / 100% | 9% / 25% / 28% |
| ETH | 3d / 7d / 14d | 53 / 52 / 55 | 74% / 90% / 97% | 92% / 100% / 100% | 15% / 17% / 33% |
| HYPE | 3d / 7d / 14d | 47 / 41 / 27 | **64% / 86% / 93%** | 91% / 100% / 100% | 6% / 34% / **63%** |
| SOL | 3d / 7d / 14d | 48 / 54 / 38 | 72% / 85% / 98% | 96% / 98% / 100% | 6% / 26% / 58% |

这支持“确认后持有和滚仓”这个交易直觉，但有两个边界：

- 表内方向和强趋势身份都由完整 future path 事后定义，不能把 `24h` 剩余空间误读为实时胜率。
- HYPE `14d` 强趋势里，半 MFE 保护约 `63%` 会在 horizon 前触发；有些路径先回吐一半、之后又创新高。因此“允许回吐一半”适合 `3d/7d` 的多数强趋势，却仍可能过早切断两周级二次加速。

状态寿命也支持把 campaign 设计在 `3–14d`：共同窗中各资产 Long/Short 状态 episode 中位数大致 `2–3.5d`，P90 多在 `8–13d`。问题不在 horizon 选择离谱，而在状态定义有没有预测力。

## 5. 事前识别一：过去 7d/28d 同向

共同窗口内，按每个 admission 事件等权汇总的成本+funding 后均值：

| 资产 | 3d | 7d | 14d | 方向拆解 |
|---|---:|---:|---:|---|
| BTC | +0.20% | +0.67% | +0.47% | Long 全负，Short 为 +0.77% / +2.02% / +2.53% |
| ETH | +0.15% | +0.53% | +1.71% | Long 全负，Short 为 +1.02% / +2.32% / +4.40% |
| HYPE | **-1.52%** | **-3.02%** | **-3.12%** | Long、Short、三档 horizon 全负 |
| SOL | -0.08% | -0.05% | -0.56% | Long 全负，Short 为正但不足以抵消 |

各自全历史背景没有替 HYPE 翻案：HYPE 为 `-1.25%/-2.67%/-3.15%`；BTC 为 `+0.10%/+0.50%/+0.87%`，ETH 为 `+0.04%/+0.99%/+1.68%`，SOL 仍为负。

这说明：

- HYPE 失败不是因为 Long/Short 被平均抵消；两个方向都失败。
- BTC/ETH 的结果说明“多资产完全没用”也不成立，但共同窗利润主要来自 Short，存在强烈方向/市场阶段依赖。
- 已揭示历史上的正均值不是可上线策略；它还没有独立的 selector、止损、仓位、组合冲突处理和 prospective OOS。

## 6. 事前识别二：让行情先走 4h/12h/24h

该扩展在主 habitat/admission 结果揭示后、计算前另行冻结，只能做机制诊断。方向只取最初价格位移符号，强度只取 `位移/(历史波动×sqrt(时间))`，不使用任何技术指标。

最关键的结果是：**初始位移越大、速度越快，并不普遍带来更强延续。** 以最高三分之一强度、等待 `4h` 后入场为例，成本+funding 后均值为：

| 资产 | 共同窗 3d / 7d / 14d | 各自全历史 3d / 7d / 14d |
|---|---|---|
| BTC | -0.03% / +0.07% / +0.13% | +0.01% / -0.11% / -0.31% |
| ETH | **+0.88% / +0.43% / +0.70%** | **+0.53% / +0.76% / +0.85%** |
| HYPE | +0.02% / **-1.05% / -1.12%** | **-0.20% / -1.43% / -1.45%** |
| SOL | -0.47% / -0.51% / +0.24% | -0.58% / -0.53% / -0.03% |

等待 `24h` 也没有救回 HYPE。HYPE 最高强度组三档净均值为 `-0.89%/-2.18%/-3.23%`；最低强度组反而约为 `+0.05%/+0.31%/+1.52%`。这更像过度伸展后的反转，不像惯性越大、延续越强的简单物理系统。

ETH 的 `4h` 高强度现象是本轮唯一跨共同窗与各自全历史都保持同号、且三档 horizon 均为正的 onset 候选。但它来自已揭示数据、分组重叠且未经独立 OOS，只能成为下一轮独立研究假设，不能现在宣布有效。

## 7. 对 Trend Campaign Engine 的含义

本轮把问题拆成了三层：

| 层 | 验证结果 | 含义 |
|---|---|---|
| 趋势事件是否存在 | 四币都存在 | 趋势策略的利润原料存在，不是理论上不可能 |
| 强趋势开始后是否还有尾巴 | 事后强趋势中明显存在 | 持有、分段加仓、动态保护值得研究 |
| 当时能否识别它 | HYPE 两种纯价格识别均失败；BTC/ETH 部分成立 | 当前瓶颈是 admission/confirmation，不是 exit 参数 |

因此，下一步不应继续围绕 HYPE 优化止损、Donchian 或传统指标，也不应直接回测四币同参数组合。更合理的后续合同是：

1. 四币分开冻结 admission family；HYPE 不因振幅大而自动入选。
2. 首个候选优先验证 ETH 的 `4h` 价格位移/速度延续，BTC 作为独立长期趋势先验候选；HYPE 需要不同机制，可能更偏“试单 + 防过度伸展”，不能沿用强初速追涨杀跌。
3. 把 campaign management 和 admission 解耦：先用很小的 probe 验证，只有达到预先冻结的价格路径确认才加仓；跟踪层再单独比较 `2R` 后半 MFE、时间分段保护和重新加速后的 stop reset。
4. 新实验必须锁新的 prospective OOS；本轮窗口、`4h/12h/24h` 和三等分结果全部视为已揭示，禁止继续在同一窗口挑阈值后声称验证成功。

## 8. 限制

- 日频 anchor 和多 horizon 高度重叠；共同窗只有约 `27` 个独立 14 日块。
- 事后强趋势的延迟捕获是 oracle habitat，不是交易信号。
- onset 三等分是揭示后诊断；目前没有为 high-minus-low 单独建立 prospective inference。
- 本轮没有订单级 stop、加减仓、杠杆、组合资金占用或策略收益；不能从 hypothetical horizon return 推导实盘收益。
- 结论只覆盖现有 Binance 数据历史；HYPE 历史尤其短，不能代表多个完整牛熊周期。
