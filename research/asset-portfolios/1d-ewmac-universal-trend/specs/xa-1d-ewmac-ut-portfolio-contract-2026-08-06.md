## 1. 继承项（自 P1 合同冻结，本轮禁止改动）

- 信号：EWMAC 四速集成（8/32、16/64、32/128、64/256，scalar 5.3/3.75/2.65/1.87，截断 ±20，≥2 对可用，T−1 收盘信息）。
- 单资产子系统仓位：`w_i = (F_i/10) × (20% / σ_i)`，σ_i 为日收益 EWMA（半衰期 20）年化（加密 ×√365，TradFi ×√252）。
- 数据身份与 P1 完全同批：加密 = 15m 湖重采样 UTC 日线（BTC/ETH/HYPE，跨源去重规则同 P1）；TradFi = P1 已留档的 Yahoo 原始 JSON（QQQ/SPY/SOXX/GLD/SLV/SOYB，SHA256 见 [`manifest_2026-08-05.json`](../artifacts/yahoo_raw/manifest_2026-08-05.json)），adjclose 调整口径同 P1。

## 2. P2 变化项：组合构造（全部预注册，禁止搜索）

- 资产池：P1 全部 9 个资产（BTC、ETH、HYPE、QQQ、SPY、SOXX、GLD、SLV、SOYB），**零剔除**——不因 P1 单资产表现好坏做任何取舍（SOYB、HYPE 照常入池）；资产按 point-in-time 激活（≥2 个速度对可用且波动率估计就绪即进入，HYPE 2025-08 起、SOYB 2012 起自然晚进）。
- 等风险分配：当日活跃资产数为 `N_t`，每资产原始权重 `raw_i = w_i / N_t`。
- 组合层波动目标：用原始权重组合日收益的 EWMA（半衰期 20，T−1 截止）波动年化 ×√365，`scale = 20% / σ_p`；总名义杠杆上限 `Σ|w| ≤ 3.0`（超出时按比例压缩 scale）。最终目标 `w*_i = raw_i × scale`。
- 缓冲带：仅当 `|w*_i − held_i| ≥ 0.10 × (20%/σ_i)/N_t × scale` 时调仓到目标；资产失活（预测过期 >5 个日历日或数据终止）强制平仓。
- 联合日历：组合台账按 UTC 日历日记账；加密 7×24 逐日记收益，ETF 只在其交易日记收益（周末贡献 0，周一记录跨周末收益）；预测/波动用各自原生交易日序列计算后 ffill（上限 5 日）。台账终点 = 加密湖终点 `2026-08-02`。
- 成本（两套台账，门禁只判压力台账）：
  - **压力台账（gate 口径）**：加密腿 = 手续费 `0.001` + 滑点 `4 bps`/边 + 逐日 as-of 资金费；TradFi 腿 = `10 bps`/边。
  - 诊断台账：TradFi 腿 0 成本，其余同上；只报告，不判门禁。

## 3. 评估窗口

- 主窗：首个"活跃资产 ≥ 4"的日历日（约 2005 年，GLD 激活后）至 `2026-08-02`，约 21 年。
- 加密时代子窗：BTC 激活日（约 2020-中，365 日暖机后）至 `2026-08-02`——9 资产池成形的现代段，单独判门禁。
- 近期分片（锚定台账终点，仅审计）：最近 `1d/7d/1m/3m/6m/1y`。
- 暴露声明：同 P1，历史无干净 OOS，参数文献冻结缓解；2026-08-06 之后为干净前瞻窗。

## 4. 预注册门禁（压力台账）

1. G1 主窗净收益 > 0 且净 Sharpe ≥ 0.7；
2. G2 主窗最大回撤 < 25%；
3. G3 加密时代子窗净 Sharpe ≥ 0.6 且最大回撤 < 25%；
4. G4 主窗组合年单边换手 ≤ 15×（名义/权益）；
5. G5 leave-one-out 稳健性：加密时代子窗内，逐一剔除任一资产后重跑（9 次），组合净收益全部仍 > 0。

判定纪律：

- 任一条不过 → 本契约的组合路线判死；禁止在同一历史上调整资产池、风险分配、波动目标、杠杆上限或缓冲带后重跑再引用（任何构造变化 = 新契约）。
- 全过 → 可提议登记 V1（登记需用户确认且登记 ≠ 晋升）；晋升另走验证门禁（含 Binance TradFi 永续真实成本/资金费/流动性审计、执行时序审计、前瞻观察）。
