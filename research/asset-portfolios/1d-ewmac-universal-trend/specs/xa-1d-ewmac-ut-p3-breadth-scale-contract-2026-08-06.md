## 3. P3 变化项二：scale 死区（10%）

- 每日照常计算理论 scale = `20% / σ_p`（σ_p 估计口径同 P2：原始权重组合日收益 EWMA 半衰期 20，T−1 截止）。
- **实际使用的 scale 保持不变，仅当理论值相对当前使用值偏离超过 `10%` 时，一次性更新到理论值。**
- 总杠杆上限的执行不变：当日 `Σ|raw|×scale > 3.0` 时按 `3.0/Σ|raw|` 截取当日生效 scale（不更新死区基准值），持仓层越界压缩规则亦保持 P2 原样。
- 资产层 0.10 缓冲带不变——本轮只新增 scale 死区这一个执行层机制。

## 4. 预注册门禁（压力台账，与 P2 完全一致）

1. G1 主窗净收益 > 0 且净 Sharpe ≥ 0.7；
2. G2 主窗最大回撤 < 25%；
3. G3 加密时代子窗净 Sharpe ≥ 0.6 且最大回撤 < 25%；
4. G4 主窗年单边换手 ≤ 15×；
5. G5 leave-one-out 稳健性：加密时代子窗逐一剔除任一资产重跑（18 次），组合净收益全部仍 > 0。

判定纪律：

- 任一条不过 → 本构造判死，禁止同历史调整资产池、死区宽度、缓冲带、波动目标或杠杆上限后重跑再引用（任何变化 = 新契约）。
