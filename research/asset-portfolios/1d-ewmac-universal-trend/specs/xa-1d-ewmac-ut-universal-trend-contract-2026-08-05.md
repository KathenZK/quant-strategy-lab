# XA-1D-EWMAC-UT 通用趋势冻结合同

> 状态：`registered`（研究契约，非晋升）。冻结日期：2026-08-05（UTC+8），在跑任何回测**之前**冻结。
> 研究问题：**一套文献标准的 EWMAC 多速趋势参数（零逐资产调参），能否在 BTC/ETH（/HYPE）上净收益成立，并在用户实际想交易的美股/商品类标的上验证通过？**
> 背景：MA7 单资产线已全线判死（7 天尺度信号换手成本不可养，多资产迁移全部失败）；本合同改用 30–256 天尺度的连续预测集成，参数全部取自公开文献（Carver, *Systematic Trading*），不在本仓库任何历史数据上调参。

## 1. 信号（EWMAC 四速集成，文献冻结）

- 速度对（EMA span，日）：`(8,32)`、`(16,64)`、`(32,128)`、`(64,256)`。
- 单对原始预测：`(EMA_fast − EMA_slow) / σ_price`，其中 `σ_price` 为日价格变化（价格单位）的 EWMA 标准差，半衰期 20 日。
- 单对 forecast scalar（文献值，不重估）：`5.3 / 3.75 / 2.65 / 1.87`；单对与合成预测均截断于 `±20`。
- 合成：可用速度对的等权平均；速度对在资产历史 ≥ 慢腿 span 日后才可用；可用对 < 2 时不持仓。forecast 分散乘数固定 1.0（保守简化，声明）。
- 全部计算只用 T−1 收盘及更早数据。

## 2. 仓位（单资产独立、波动率目标、缓冲带）

- 目标权重：`w* = (F/10) × (20% / σ_ann)`，`σ_ann` 为日收益 EWMA 标准差（半衰期 20 日）年化（加密 ×√365，TradFi ×√252，均 T−1 截止）；`|w*| ≤ 2.0`。
- 缓冲带（换手控制，冻结不调）：仅当 `|w* − w_held| ≥ 0.10 × (20% / σ_ann)`（满预测仓位的 10%）时调仓到目标，否则持仓不动。
- 执行时序：T−1 收盘后计算，T 日按收盘-收盘收益持有（1d 粒度近似，与 TSMOM P0 同口径）；预测不可用时目标为空仓。

## 3. 资产、数据与成本

主判定盘（加密，Binance USDT 永续）：

- `BTC`（2019-09 起）、`ETH`（2019-11 起）；`HYPE`（2025-05 起，约 1.2 年样本，只报告不判门禁）。
- 数据：已审计 15m 归一化湖按 UTC 日边界重采样 `1d`（open=first/high=max/low=min/close=last/量额=sum）；跨源重复键去重优先 `binance_vision_kline_monthly`（ETH 重叠段 1656 个日收盘两源零差异，已预校验）；首尾不完整日丢弃。
- 成本：换手名义 × (手续费 `0.001` + 滑点 `4 bps`)/边（仓库 Binance 默认）；资金费逐日 as-of 求和计入（多头付正费率），报告覆盖率。

## 5. 预注册门禁

加密主门禁（BTC 与 ETH 各自独立判定，两者须同时全过；净口径含费用+资金费）：

1. G1 全期净收益 > 0；
2. G2 净 Sharpe ≥ 0.5；
3. G3 最大回撤 < 40%；
4. G4 年单边换手 ≤ 15×。

TradFi 验证门禁（逐标的判定）：

1. V1 0 成本全期净收益 > 0，且 `10 bps`/边敏感度下仍 > 0；
2. V2 净 Sharpe ≥ 0.3（0 成本口径）；
3. V3 最大回撤 < 40%。

判定纪律：

- BTC/ETH 任一未全过 → "EWMAC 通用加密趋势"路线判死；禁止在同一历史上调整速度对、scalar、波动目标或缓冲带后重跑引用（任何参数变化 = 新契约）。
- 加密过、TradFi 大面积失败（≥4/6 标的未过）→ "跨资产通用"主张判死，只能按资产类别另立契约。
- 全过 → 可提议登记 V1（登记仍需用户确认且登记 ≠ 晋升）；晋升另走验证门禁（含消融、稳健性、执行审计）。
- 对照义务：每资产报告同窗口买入持有（毛价格口径）的收益/波动/MDD/Sharpe；本合同的主张是"绝对正的风险调整收益"，不主张跑赢买入持有，但必须并排如实呈现。
