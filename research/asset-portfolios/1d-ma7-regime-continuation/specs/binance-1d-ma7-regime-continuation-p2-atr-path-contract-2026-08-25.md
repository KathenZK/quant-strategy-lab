# BIN-1D-MA7-RC P2 ATR 路径市场风格合同（2026-08-25）

## 研究问题

P2 不再把“当前波动率处在自身历史高位还是低位”当成主要市场风格，而是直接检验用户提出的两种路径：

1. ATR 在突破前持续下降，随后向上突破 MA，是否更容易启动上涨延续；
2. ATR 在突破前持续上升，随后向下跌破 MA，是否更容易形成下跌延续。

P2 与 P1 使用同一冻结数据源、同一截止日和同一未来收益定义；但 P2 重新从日线面板构造事件，不继承 P0/P1 的 `RV252` eligibility。这样主指标只需要 60 个历史观测，不能让旧的 252 日要求继续暗中排除新合约。

## 数据和事件

- Universe：冻结数据源中出现过的全部 Binance USD-M perpetual，不做 crypto-only、当前成分或人工选币过滤。
- 日 K：已审计 `15m` 数据因果聚合出的完整 UTC 日 K；一天必须有 96 根闭合 `15m`。
- 截止：`2026-07-01 00:00:00 UTC` 之前。
- 合约年龄：仍要求真实首次观测后至少 120 天；这是上市成熟度要求，不是 ATR 计算窗口。
- 主事件：SMA7 close cross；SMA5/10 只做邻域稳健性。
- 多头：`Close[t-1] <= SMAp[t-1]` 且 `Close[t] > SMAp[t]`。
- 空头：`Close[t-1] >= SMAp[t-1]` 且 `Close[t] < SMAp[t]`。
- 观察：trigger close 到未来 `1/3/5/10/20/40D` close 的方向收益，同时保留 ATR 标准化收益。
- P2 仍不模拟成交、持仓、退出、换仓、费用、滑点或 funding，因此没有年化和回撤。

## 大白话市场风格

### 突破前十天，市场是在安静还是变剧烈

先计算每个合约的 ATR20。事件发生在第 `t` 天时，只看截至 `t-1` 的数据：比较 `t-1` 的 ATR20 与 `t-11` 的 ATR20，得到突破前十天 ATR 下降或上升了多少。

然后把这个变化速度与同一合约最近 60 次历史观测比较，固定分成五档：

| 档位 | 大白话标签 |
| --- | --- |
| Q1 | ATR 下降最快，市场快速收缩 |
| Q2 | ATR 温和下降 |
| Q3 | ATR 大致稳定 |
| Q4 | ATR 温和上升 |
| Q5 | ATR 上升最快，市场快速扩张 |

这是因果滚动排名，不使用整段历史的事后边界。60 是当前风格比较窗口；合约仍须上市满 120 天，因此指标历史不足不会提前放行新合约。

为了贴近“不断下降/不断上升”，另外保留一个不调参的严格标签：最近十次 ATR 日变化中至少七次同向，且变化速度属于 Q1/Q5，分别叫 `PERSISTENT_CONTRACTION` 和 `PERSISTENT_EXPANSION`。

### 突破当天有没有突然爆发

把突破当天 True Range 与突破前一日 ATR20 比较：

- `<0.8`：`WEAK`，当天范围比平常小；
- `0.8–1.2`：`NORMAL`，与平常接近；
- `>1.2`：`BURST`，当天范围明显放大。

这三个固定阈值在读取 P2 收益前冻结，不根据最好结果回头调整。

### MA 方向确认

- 多头只把 `SMAp[t] - SMAp[t-1] > 0` 记为方向一致；
- 空头只把 `SMAp[t] - SMAp[t-1] < 0` 记为方向一致；
- 斜率除以前一日 ATR20只用于比较强弱，符号判定不依赖资产价格尺度。

## 预先声明的输出

1. 所有 MA7 事件与 MA7 斜率一致事件；
2. 斜率一致后的五档 ATR 路径；
3. 五档 ATR 路径 × 三档突破日范围；
4. `PERSISTENT_CONTRACTION` 与 `PERSISTENT_EXPANSION`；
5. 用户的两个直接假设：多头 `Q1 + BURST`、空头 `Q5 + BURST`；
6. 每组总次数、涉及合约数、不同事件日数、日/周/月频率；
7. 年份、BTC 市场阶段、动态 Top20 流动性池/长尾、MA5/7/10 邻域；
8. 同一样本上的 ATR 路径五档与上一轮 RV252 历史高低五档对比。

每个收益格输出样本数、均值、中位数、胜率、symbol/date 双向聚类 t-stat 与 95% 置信区间。小样本或同日集中不能用普通事件数包装成独立证据。

## 与上一轮怎样公平比较

P2 主样本使用 60 日风格窗口，所以会比 P1 保留更多事件。为了避免“样本变了”造成假胜负，报告同时给两种视角：

1. P2 全样本：回答 60 日定义实际能覆盖多少新合约和事件；
2. 共同样本：只保留同时具有 P2 ATR 路径和 P1/P0 `RV20 rolling-252 percentile` 的 MA7 斜率一致事件，在完全相同事件上比较两种分法。

比较重点不是哪一个历史小格均值最高，而是五档是否平滑、跨年份是否保持排序、极端档差异是否有足够样本和聚类置信度。

## 结论边界

- P2 是已揭示历史上的 diagnostic observation，不是 clean OOS。
- P2 不允许把历史最好格直接写成参数，也不产生策略年化。
- 只有多空至少一边出现样本充足、跨期相对稳定、MA5/7/10 邻域方向一致的结构，才另立账户策略合同。
- 账户策略必须重新冻结 next-open、持有/退出、同币重复信号、选币、最大持仓数、换仓、费用、滑点和 funding。
