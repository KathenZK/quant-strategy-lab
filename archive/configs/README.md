# Archived Configs

This directory keeps retired top-level configuration examples.

These files are historical references only. Active data commands can run with
`load_settings(None)`, which resolves the repository data lake paths from
`src/strategy_lab/settings.py`.

- `environments/binance-spot-1h-local.yaml`: former local Binance spot 1h environment example.
- `examples/environment.example.yaml`: former environment shape example.
