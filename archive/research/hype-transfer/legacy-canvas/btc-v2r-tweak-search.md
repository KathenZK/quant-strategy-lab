在不改变 V2R 指标体系的前提下，微调 ADX、成交量、仓位、止盈和退出逻辑，验证 BTC 是否能跑通。

Source: local Binance BTC/USDT perp 15m data lake, 2025-05-15 to 2026-05-27 UTC. Search tested 1297 parameter sets. Includes 8.5 bps entry and exit cost plus funding.

## 结论

| 问题 | 判断 | 证据 |
| --- | --- | --- |
| 能否跑正 | 可以，但很勉强 | 最佳候选 1y +1.92%，最大回撤 -1.87%，只有 14 笔交易 |
| 是否值得迁移 | 不建议直接作为 BTC 策略 | 费用 x2 后变成 -0.38%，费用 x3 后 -2.63% |
| 有效微调方向 | 极严格、低仓位、只做多 | ADX >= 40、volume_surge >= 1.0、target ATR 0.003、cap 1x |
| 核心判断 | 机制有一点残余边际，但不是强 alpha | 收益薄、样本少、成本敏感，和 HYPE V2R 的高收益结构完全不同 |

## 最佳微调参数

| 参数 | 值 | 原因 |
| --- | --- | --- |
| 方向 | long only | BTC 空头在这套逻辑下贡献很差，最佳候选直接禁用空头 |
| Keltner | 关闭或 2.0 均可 | 前排候选结果一致，说明强 ADX/成交量过滤已经覆盖了通道约束 |
| ADX | ADX28 >= 40 | 从 HYPE 的 28 提高到 40，BTC 必须只做极强趋势 |
| 成交量 | volume_surge_192 >= 1.0 | 从 HYPE 的 0.25 提高到 1.0，过滤大部分无效趋势 |
| 仓位 | target ATR 0.003，cap 1x | 从 HYPE 的 0.016 大幅降低，否则指标退出亏损太大 |
| 止盈 | 3ATR | 从 HYPE 的 4ATR 降到 3ATR，BTC 趋势延展不如 HYPE，需要更快兑现 |
| 指标退出 | delayed2：连续 2 根触发才退出 | 减少单根噪音导致的过早退出 |
| 回撤降仓 | 保留 -12% 后新仓 70% | 最佳候选回撤很低，实际影响很小 |
