# Archive

This directory keeps historical project material that should not define the active research workflow.

## Contents

- `code/platform/`: small historical strategy source snapshots cited by durable research docs; not a runnable platform archive.
- `configs/`: retired top-level environment configuration examples.
- `docs/`: retired planning, migration, and Cursor artifact index documents.
- `research/`: retired strategy research and platform experiment documents.
- `scripts/research/`: one-off historical research, plotting, comparison, and backtest scripts.
- `reports/legacy/`: small tracked report artifacts that used to live under `reports/`.

## Rule

Archive content is evidence, not the current entrypoint.

Read active project docs first:

- `README.md`
- `AGENTS.md`
- `research/README.md`
- `research/hype/README.md`
